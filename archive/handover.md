## Key technical lessons

1. **Babel-standalone with `<script type="text/babel" src="...">` does not share module scope.** `const X` in one jsx file is NOT accessible in another. Either (a) use `window.X = ...` then `const X = window.X` alias at top of consumer, or (b) inline the dependency. We use both patterns.
2. **React rejects `{en, zh}` objects as children** without a unwrapper call. Every value pulled from `data.js` that's not a known string must go through `Tt(value, lang)` or a `typeof === "string"` guard. SSR with `react-dom/server` catches these — bun + transpiler classic JSX runtime works for this test.
3. **Service Worker is sticky.** Bumping `VERSION` invalidates cache for new visitors but existing PWA installs may need re-add to home screen for hardest cache reset.
4. **GitHub Pages URL is case-sensitive** for repo name. Repo is `Health-Check` so URL must use the same case.
