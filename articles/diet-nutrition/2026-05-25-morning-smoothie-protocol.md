# Morning Smoothie Protocol（每日優格飲 SOP）

**建立日期**：2026-05-25（**2026-05-27 v3 修訂**：大麥麥片 + 奇亞籽 → 亞麻籽粉 15g；**2026-06-03 v4 新增**：黃金奇異果版 + 酪梨版命名變體，見 §九；**2026-06-14 v5 新增**：豆奶羽衣甘藍藍莓版（綠飲 × 藍莓交叉版，無優格/乳清），見 §九變體 C；**2026-06-29 v6 新增**：當令甜櫻桃季節變體 + 全櫻桃 RCT 證據與 100g 次劑量提醒，見 §十一）
**用途**：個人早餐標準配方 + 替換矩陣 + 季節輪替表
**對應目標**：AHA Life's Essential 8 第 1（飲食）、5（BMI）、6（LDL）、7（血糖）、8（BP）
**相關**：傍晚綠拿鐵（葉菜版、加餐替代）與 RCT 證據 → [`2026-06-12-green-smoothie-rct-review.md`](2026-06-12-green-smoothie-rct-review.md)

## 一、主配方（每日 baseline）

加入順序：

1. **杏仁奶（無糖）** 100 cc
2. **無糖優格** 150 g
3. **亞麻籽粉（現磨 / 冷藏）** 15 g 🆕（2026-05-27 v3：取代大麥麥片 + 奇亞籽）
4. **Vit D3 3000 IU + K2**
5. **藍莓** 60 g
6. **Citrulline** 4 g
7. **乳清蛋白** 1 scoop

**估算營養**：~410 kcal、蛋白 ~37 g、纖維 ~7 g、ALA ω-3 ~3.5 g

> **2026-05-27 v3 變更**：大麥麥片 + 奇亞籽 → **亞麻籽粉 15 g**。理由：一項材料同時補足可溶性纖維、ALA ω-3（取代原 chia）與 lignans，並涵蓋早餐移除堅果的 ω-3 缺口。**權衡**：亞麻籽**無 β-glucan**，故降 LDL 的 β-glucan 機制改由**午餐燕麥 / 大麥飯補（目標 3 g/天）**。亞麻籽務必磨碎（整顆不消化）、冷藏避免 ALA 氧化。

## 二、配方科學論據（每項對應的 CV 機制）

| 成分 | 主要機制 | 對應 LE8 |
|------|------|------|
| 亞麻籽粉 15g 🆕 | ALA ω-3 + lignans + 黏質可溶性纖維 → 降 LDL + 降 BP（Rodriguez-Leyva 2013） | 第 1、6、8 項 |
| 藍莓 | 花青素 → 內皮 NO ↑、降 SBP | 第 8 項 |
| Citrulline 4g | NO precursor → 血管擴張 → 降 SBP 3–8 mmHg | 第 8 項 |
| 乳清 + 優格 | 高蛋白 → 飽足、肌肉合成、血糖平穩 | 第 5、7 項 |
| ⚠ β-glucan 缺口 | 亞麻籽無 β-glucan；改由午餐燕麥/大麥補（目標 3g/天 FDA 降 LDL 閾值） | 第 6 項 |
| 優格益生菌 | 腸道菌相 → 系統性發炎 ↓ | 全面 |
| D3 + K2 | 鈣導向骨骼、CV 鈣化保護 | — |

## 三、配料輪替矩陣（增加多酚多樣性）

### 主莓果（每日 30–60g，藍莓為主軸，可輪替）

| 莓果 | 替換時機 | 機制亮點 |
|------|------|------|
| 藍莓 | 主軸 | Pterostilbene、研究最強 |
| **桑椹** | **4–5 月台灣盛產時直接換** | **DNJ（天然 α-glucosidase 抑制劑）→ 血糖緩衝**、維 C 4 倍、鐵 6 倍 |
| 草莓 | 12–4 月 | 維 C、糖低 |
| 覆盆莓（冷凍） | 全年 | 纖維 6g/100g（水果之最） |
| 黑莓（冷凍） | 全年 | 花青素濃 |
| 酸櫻桃（冷凍） | 全年 | 天然褪黑激素，**有 RCT 證據改善睡眠** |

> **進階**：藍莓 20g + 桑椹 20g 雙拼 = 機制互補（BP + 血糖）
>
> ⚠️ **甜櫻桃 ≠ 酸櫻桃**：上表「酸櫻桃」是助眠補充品方向（褪黑激素，睡前用）。**當令甜櫻桃**（6–8 月鮮果）是另一回事，作早餐鮮果輪替的證據、劑量與雙拼建議見 **§十一**。

#### Tier S（機能性強，優先推薦）

## 六、⚠ 警告與避免

| 項目 | 原因 |
|------|------|
| **葡萄柚** | 與 statins、某些 CCB（amlodipine）有嚴重藥物交互作用。**未來若開始用藥需迴避** |
| **楊桃** | **腎功能不全者絕對禁食**（caramboxin 神經毒） |
| **釋迦、龍眼、荔枝、榴槤** | 糖含量 17–20g/100g，偶爾品嚐 |
| 含糖果乾、蜂蜜、楓糖漿 | 添加糖陷阱，會抵消整份配方好處 |
| 額外鈣補充劑 | 本配方單餐鈣 ~400–500mg 已接近單次吸收上限 |

> **農藥清洗（食材衛生）**：本配方水果/葉菜的逐項農藥殘留與清洗處理見 [`2026-06-22-breakfast-produce-pesticide-washing.md`](2026-06-22-breakfast-produce-pesticide-washing.md)。重點：**檸檬（皮入飲）與每日 150g 藍莓**最值得換有機（系統性殘留洗不掉）；草莓/羽衣甘藍高殘留但用量小；酪梨/奇異果去皮、農藥非考量。

## 九、命名變體配方（2026-06-03 v4 新增｜以實際 150g 藍莓為基準）

> **前提**：本人實際每日用 **藍莓 150g**（非 §一 主配方寫的 60g）。150g = **BPS-Norfolk RCT（Curtis 2019）的有效劑量**（每日 1 杯 ≈ 150g 改善內皮 / 降 SBP），屬證據支持，**予以保留**。代價是體積大 + 自藍莓糖 ~15g，這也是空間排擠乳清的根因。
>
> **空間衝突鐵則（150g 藍莓固定下的保留順位）**：
> 藍莓 150g（RCT 劑量）＞ **乳清 1 匙（主結構蛋白，永不省）** ＞ 優格 150g ＞ 配角水果（奇異果 / 酪梨，可減可砍）＞ 杏仁奶（可壓到 60cc）。
> 空間不足時，**砍配角水果、減液體，絕不砍乳清**。

### 共同空間管理技巧（150g 藍莓裝得下乳清的關鍵）

1. **改用冷凍藍莓**：結冰密實、打完體積縮小，杯內反而較省空間，且免加冰塊。
2. **杏仁奶降到 60–70cc**：液體是最可壓縮項。
3. **分兩段打**：先打藍莓 + 液體 + 酪梨/奇異果成泥（降體積），再加優格 + 乳清打勻。
4. **換 700ml+ 容量杯**。
5. **終極 fallback**：乳清用 150cc 水單獨搖開另喝（佔 0 杯內空間）。

### 變體 A — 黃金奇異果版（維 C / 纖維 / 鉀 強化）

完整清單（加入順序）：
1. 杏仁奶（無糖）100 cc（放全顆奇異果時降到 60cc）
2. 無糖優格 150 g
3. 亞麻籽粉 15 g
4. Vit D3 3000 IU + K2
5. **藍莓 150 g**
6. **黃金奇異果 ½ 顆（55 g）** 🆕（空間優先版；想放全顆 110g 須先把杏仁奶降到 60cc）
7. Citrulline 4 g
8. 乳清蛋白 1 scoop（**不可省**）

- 空間權衡：150g 藍莓 + 全顆 110g 奇異果 + 乳清會滿出（= 今早狀況）→ 預設 **奇異果切半 55g**；要全顆則減杏仁奶。
- 切半保存：剩半顆連皮、切面貼膜冷藏，隔天用。
- 估算（半顆版，150g 藍莓基準）：~425 kcal、蛋白 ~37g、纖維 ~9.5g、維 C 滿日 RDA、糖 ~20g。

### 變體 B — 酪梨版（健康脂肪 / 飽足 / 脂溶吸收強化）

完整清單（加入順序）：
1. 杏仁奶（無糖）**60–70 cc**（減量，酪梨增稠）
2. 無糖優格 150 g
3. 亞麻籽粉 15 g（當天不加量）
4. Vit D3 3000 IU + K2
5. **藍莓 150 g**
6. **熟酪梨 ¼ 顆（~50 g）** 🆕
7. **檸檬汁 ½ 顆** 🆕（提亮 + 抗氧化護色）
8. Citrulline 4 g
9. 乳清蛋白 1 scoop（**不可省**）

- 必要條件：酪梨**必須夠熟**（生硬 → 澀 + 顆粒，改走加熱熟食、不入飲）；**現切現打**避免褐變 + actinidin/酪梨酶使優格出水變稀。
- 估算（150g 藍莓基準）：~475 kcal、蛋白 ~37g、纖維 ~11g、MUFA ~6–7g、糖 ~16g（酪梨幾乎不加糖）。當天勿再加堅果，避免破 500 kcal。

### 三版對照表（皆為 150g 藍莓基準）

| 項目 | 主配方（150g 藍莓） | 變體 A 黃金奇異果版 | 變體 B 酪梨版 |
|------|------|------|------|
| 新增配角 | — | 黃金奇異果 ½ 顆 55g | 熟酪梨 ¼ 顆 50g + 檸檬汁 ½ |
| 杏仁奶 | 100 cc | 100 cc（全顆奇異果則 60cc） | **60–70 cc**（減量） |
| 熱量 | ~390–410 kcal | ~425 kcal | ~475 kcal |
| 蛋白質 | ~36–37 g | ~37 g | ~37 g |
| 纖維 | ~8 g | ~9.5 g | ~11 g |
| 脂肪特性 | ALA ω-3 ~3.5g | ALA 為主 | **+MUFA 6–7g（脂溶吸收↑）** |
| 維 C | 低 | **+~85 mg（滿 RDA）** | +~20 mg（檸檬） |
| 鉀 | baseline | +~170 mg | +~175 mg |
| 糖（含藍莓 ~15g） | ~15 g | ~20 g | ~16 g |
| 主要強化 | 花青素（RCT 劑量） | 抗氧化 / 維 C / 纖維 | 健康脂肪 / 飽足 / 脂溶吸收 |
| 最佳時機 | 每日 baseline | 一般日 / 想補維 C | 拉長飽足 / LDL-BP 強化日 |
| 空間風險 | 低 | **中**（全顆會排擠乳清） | 中（須減杏仁奶留稠度空間） |
| 注意 | — | 全顆須減杏仁奶；切半保存 | 須夠熟；現切現打；勿再加堅果 |

> **選用邏輯**：想壓糖 / 增飽足 / 顧 LDL-BP → 變體 B；想補維 C / 增纖維且非介意糖 → 變體 A；兩者皆 **150g 藍莓 + 乳清不動**，只在配角與液體上取捨。

## 十、變體 C — 豆奶羽衣甘藍藍莓版（綠飲 × 藍莓交叉版｜2026-06-14 v5 新增）

> **定位說明（重要）**：本變體與 §九 三版**不同家族**。§九 以「150g 藍莓 + 優格 + 乳清不動」為鐵則，是**高蛋白早餐**（蛋白 ~37g）；變體 C **改用豆奶為 base、加入羽衣甘藍、含優格但不含乳清**，是「綠拿鐵 × 藍莓」的中蛋白優格綠飲交叉版，蛋白質約 ~13–15g。本人 2026-06-14 早上實作，主觀評為「最近最好喝」的一杯。
>
> ⚠️ **蛋白質落差提醒**：此版有優格（~7–9g 蛋白 + 益生菌）但**無乳清**，總蛋白約 ~13–15g，仍低於 §九 主家族的 ~37g。若要當扎實早餐主食，可另搖一匙乳清配水補足；否則作為「中蛋白優格綠飲」已是合理早餐底子。

### 完整清單（本人 2026-06-14 實作配方）

1. **義美無糖豆奶** 150 mL（base，取代杏仁奶）
2. **嫩羽衣甘藍葉** 20 g
3. **冷凍藍莓** 120 g
4. **薄切檸檬 1 片 + 檸檬纖維 ½ 份**（用 Costco「Lemon / Citron」= 美國黃檸檬 *Citrus limon*，Eureka/Lisbon 品種；"Citron" 為法文「檸檬」之雙語標示，非香櫞。比台灣綠檸檬/萊姆**低酸、皮油香氣濃**，是這杯好喝的隱藏功臣）
5. **酪梨 ½ 顆（~40 g）**
6. **雪方優格 ~100 g**（提供蛋白 + 益生菌）

> **本次刻意不加亞麻籽**：因為已加酪梨提供脂肪，避免脂肪 / 熱量疊加。

### 製作心得與技巧（本人實作筆記）

- **黏度偏高 → 最後務必加水調稀**（全部打起來偏稠）。
- **檸檬纖維建議先冷凍成冰塊再用**：直接冰進冷凍櫃做成檸檬纖維冰塊，製作時丟入，**才能保留纖維**（並兼具冰塊降溫、免另加冰）。
- 冷凍藍莓本身即提供結冰密實 + 降溫效果（呼應 §九「改用冷凍藍莓」技巧）。

### 未來調整方向

- ✅ 可改用**冷凍檸檬纖維冰塊**直接丟入（保留纖維，見上）。
- ❌ **不採用冷凍香蕉**（2026-06-14 明確排除）。

### 估算營養（粗估，依上方實作份量）

| 項目 | 數值 | 備註 |
|------|------|------|
| 熱量 | ~260 kcal | 含優格但無乳清 |
| 蛋白質 | ~13–15 g | 豆奶 ~6g + 雪方優格 ~7–9g，無乳清 |
| 纖維 | ~7–8 g | 藍莓 + 酪梨 + 羽衣甘藍 + 檸檬纖維 |
| 脂肪 | ~11 g（MUFA 為主） | 酪梨 + 豆奶 + 優格 |
| 糖 | ~13–15 g | 藍莓天然糖為主（+ 優格乳糖微量） |
| 機能亮點 | 花青素 + 葉綠素/葉黃素 + MUFA + 鉀 + 益生菌 | 抗氧化 / 內皮 / BP / 腸道取向 |

> **與主家族取捨**：變體 C 是「中熱量、中蛋白、高抗氧化」的優格綠飲；§九 是「中熱量、高蛋白」的早餐。依當天需求選用：想要飽足耐餓的扎實早餐 → §九；想要清爽抗氧化又有基本蛋白與益生菌 → 變體 C（要更飽可補一匙乳清）。

### 蛋白定位與補強建議（2026-06-14 諮詢結論）

**核心問題**：這杯 ~13–15g 蛋白夠不夠？→ **看定位**。

- **單餐最佳化原則**：MPS（肌肉蛋白合成）單餐約 **0.4 g/kg ≈ 66kg 之 25–30g**，且需跨 **leucine ~2.5–3g** 啟動門檻。乳清是 leucine 密度最高、吸收最快的來源。
- **減重保肌脈絡**：本人現處減重至 65kg + 阻力訓練階段，蛋白目標應拉到 **1.2–1.6 g/kg ≈ 每日 80–105g**（非一般保健 53–66g）；蛋白高 TEF + 飽足，同時利於減脂與保肌。

| 定位 | 目前 13–15g 評價 | 動作 |
|------|------------------|------|
| **正餐早餐** | 偏低（約單餐最佳值一半） | **補到 25g+**：加 1 匙乳清（→ ~37–40g），或飲品搭 2 顆蛋（~13g → 合計 ~26g） |
| **加餐 / 點心** | 足夠 | 不必加 |

**加乳清的權衡與作法**：
- 怕毀掉現有風味 → **乳清用 150cc 水單獨搖開另喝**（§九「終極 fallback」），飲品本身不動。
- 想合一杯 → 分兩段打（先打藍莓+豆奶+酪梨成泥，再加優格+乳清），最後加水調稀。
- 熱量：加乳清 +~100–120 kcal → 總 ~370–380 kcal，減重期仍合理。

> **一句話**：當早餐 → 補蛋白到 25g+（最省事是乳清配水分開喝，保留風味）；當加餐 → 維持現狀即可。

## 十一、當令甜櫻桃季節變體 + RCT 證據（2026-06-29 v6 新增）

> **觸發**：6–8 月甜櫻桃盛產，問「全櫻桃要幾顆 / 每日 100g 的好處有無 RCT」。結論：**可作當令鮮果輪替，但別把它當治療劑量或尿酸主力。**

### 換算（甜櫻桃一顆約 8g 整顆 / 去核 ~7g 果肉）

| 去核果肉 | 顆數（約） | 糖（櫻桃 ~13g/100g） |
|------|------|------|
| 60g（§一主配方莓果量） | 8–9 顆 | ~8g |
| 80g | 11 顆 | ~10g |
| **100g（建議全櫻桃量）** | **13–14 顆** | ~13g |
| 150g（對標藍莓 RCT 劑量） | 20 顆 | ~19–20g |

### 全櫻桃的 RCT 證據（甜櫻桃 *Prunus avium*；依強度排）

> **關鍵前提**：絕大多數陽性 RCT 用 **280g/天**，非 100g。100g（~13–14 顆）約研究量 1/3，屬**次劑量**，效益按比例打折。

| 指標 | 證據 | 研究劑量 | 對本人意義 |
|------|------|------|------|
| 尿酸（急性） | Jacob 2003：健康女性 280g 甜櫻桃，5h 後血漿尿酸↓~14%（214→183 μmol/L） | 280g 空腹單次 | **保留**：受試者本來尿酸正常（~3.6 mg/dL）。本人 UA 8.9 屬高尿酸族群，**酸櫻桃在真痛風 RCT null（Stamp 2020）**，全櫻桃預期降幅有限 |
| 發炎（IL-6 / CRP） | 42 天 pilot 每日 280g → IL-6、AGP-1 顯著↓；Jacob 2003 CRP 邊際↓ | 280g × 42 天 | 中：抗發炎是櫻桃較一致方向 |
| 血糖（HbA1c） | 同 42 天 pilot（280g）→ HbA1c、平均血糖↓、GGT/LDH↓（護肝訊號） | 280g × 42 天 | 中：方向正向，但劑量遠高於 100g |
| 血壓 | meta-analysis（2022）整體**無顯著效果**；僅「深色甜櫻桃 in 肥胖成人」RCT 見 SBP↓ | 變動 | **弱/不一致**：勿期待降 BP |
| 血脂（LDL/TG） | meta-analysis 整體 **null**；僅「不健康/肥胖」次組見 LDL/TG↓ | 變動 | **弱** |
| 睡眠 | 那是**酸櫻桃（褪黑激素）睡前**，與早上全櫻桃無關 | — | 不適用 |

### 操作建議（v6）

1. **首選雙拼，非全櫻桃**：`藍莓 100g + 櫻桃 50g` — 保留藍莓 150g 的 RCT 主軸（Curtis 2019 內皮/SBP）效益大半，櫻桃補多酚多樣性與當令風味，糖也低於全櫻桃 100g。
2. **真要全櫻桃**：100g（13–14 顆）為合理上限；衝 150g（20 顆）須走酪梨骨架 + 不加其他配角水果壓糖。
3. **去核、整顆鮮果、分裝冷凍**（盛產期囤）；**禁果汁/濃縮**（果糖升 UA + 不利減重）。
4. **別為降尿酸而加**：UA 主力仍是飲水 + 減動物嘌呤/果糖 + 腎臟科降尿酸藥（與 §三、補充品指南一致）。
5. **加入方式**：放莓果格（§一第 5 步），其餘配方不動。
