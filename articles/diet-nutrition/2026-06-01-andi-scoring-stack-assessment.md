## 一、ANDI 是什麼

**Aggregate Nutrient Density Index（聚合營養密度指數）**

| 屬性 | 內容 |
|------|------|
| 提出者 | Dr. Joel Fuhrman（"Eat to Live" 作者，2008）|
| 採用通路 | Whole Foods Market（標示體系）、Fuhrman Nutritarian 框架 |
| 分數範圍 | 1-1000，越高越營養密度高 |
| 計算邏輯 | **每卡路里**所含 34 項重要營養素（vitamins、minerals、phytochemicals、antioxidant capacity、ORAC、glucosinolates 等）的加權總和 |
| 公式（簡化） | `ANDI = (微量營養素總和 ÷ 卡路里) × 標準化係數` |

### 為什麼是「每卡」而非「每克」

ANDI 強調「**營養效率**」— 你吃進的每一卡熱量，能換回多少營養素？  
這個視角偏向**減重 / 代謝症候群 / 控制體重族群**，因為他們熱量有上限，需要每卡都「最有用」。

### ANDI 的盲點（誠實先講，最重要的一節）

ANDI 不是萬能營養指標：

| 不評估 | 後果 |
|--------|------|
| **蛋白質質量** | 蛋、魚、雞、希臘優格分數低（高蛋白稀釋每卡微量素密度） |
| **必需脂肪酸** | 鮭魚（39）、亞麻籽、堅果分數中低，但 ω-3 是必需 |
| **熱量密度高但健康的食物** | 橄欖油（9）、酪梨（28）、堅果（25-38）— 健康脂肪被嚴重低估 |
| **微生物群效益** | 優格（28）、發酵食物分數低，但 probiotic 不可替代 |
| **完整碳水/血糖** | 不區分糙米與白米的 GI 差異 |
| **加工程度** | 不考慮 NOVA 分級 |
| **生物可利用率** | 例如鈣 from kale vs 鈣 from spinach（草酸阻擋）分數相同 |
| **個體需求差異** | 高運動量者 vs 久坐者熱量需求不同 |

→ **ANDI 是「微量營養素密度」一個維度，不能單獨決定飲食**。  
→ 蛋、魚、優格、堅果、橄欖油雖然 ANDI 低，**絕對不能因為分數低就剔除**。

### 適用情境
1. 比較「同類食物」哪個更值得選（例：sweet potato vs banana 哪個 K 密度更高 → 用 ANDI 之外指標）
2. 找「填空」食物（熱量已飽和但微量素不夠時優先選高 ANDI）
3. 視覺化「沙拉 / 配菜」位置該放什麼
4. **不適用**主食、蛋白質主力、脂肪載體決策

## 四、Gap Analysis — 五大可升級空間

### 🥇 Gap 1：Tier S 綠葉攝取不足（最高 ROI）

**現狀**：每日綠葉僅早餐 15-20g kale + 午餐凱薩沙拉 ~80g 蘿蔓 ≈ 100g
**WHO / Fuhrman 建議**：≥ 400g/天蔬菜，其中綠葉 ≥ 200g
**缺口**：~ 100-150g 綠葉

**升級行動**：
- 晚餐固定加 100g 燙青菜（地瓜葉 / 空心菜 / 菠菜 / 青江菜輪替）
- 一週至少 2 次西洋菜（湯品形式：味噌 + 西洋菜 1 分鐘煮入）
- 一週至少 2 次青江菜（炒或燙）
- 凱薩沙拉的蘿蔓量 ↑（從一小碗到一大碗）

→ ANDI 加權平均可從 ~ 175 → ~ 230

### 🥈 Gap 2：十字花科（cruciferous）零覆蓋

**現狀**：完全沒有（kale 雖屬十字花科，但量極低）
**為什麼重要**：
- Sulforaphane（青花菜苗最強，成熟青花菜次之）= NRF2 誘導 + 解毒酶 + 抗發炎
- 對你 prediabetes、IOP、長期 CVD 風險都有獨立路徑

**升級行動**：
- **一週 3 次青花菜**（晚餐 100g 燙 + 橄欖油 + 蒜）
- **一週 1 次青花菜苗 50g**（撒沙拉、拌飯，sulforaphane 含量是成熟青花菜的 20-100 倍）
- **一週 1 次球芽甘藍或白花菜輪替**

→ 加上 sulforaphane 軸的長期收益

### 🥉 Gap 3：多色蔬菜不足（彩椒、紅蘿蔔、番茄）

**現狀**：番茄沙拉中極少，彩椒/紅蘿蔔 0
**為什麼**：類胡蘿蔔素多樣性（β-carotene、lycopene、capsanthin）
**升級行動**：
- 沙拉加 1/4 顆紅彩椒（生 + 維 C 高 + capsanthin）
- 番茄 1 顆/天（熟食 + 橄欖油 → lycopene 吸收 ↑）
- 紅蘿蔔絲拌沙拉或燉煮

### 4. Gap 4：豆類（legumes）缺席

**現狀**：豆漿 ✅ 但全豆（kidney beans、lentils、chickpeas）= 0
**為什麼**：可溶纖維 + 植物蛋白 + 葉酸 + Mg + 抗性澱粉
**升級行動**：
- 一週 2 次晚餐加豆子（紅腰豆湯、扁豆咖哩、鷹嘴豆沙拉）
- 罐裝即食低鈉 kidney beans 加入沙拉
- 7-11 鹽味毛豆作為點心（已有但低頻）

### 5. Gap 5：水果多樣性（莓果一支獨秀）

**現狀**：藍莓 150g ✅（很好）但其他水果 0-少
**為什麼**：anthocyanin、ellagic acid、pectin、Vit C 多樣性
**升級行動**：
- 一週輪替：草莓、覆盆莓、桑椹（季節）
- 一週 1-2 次奇異果（Vit C 高、酶輔助消化）
- 偶爾木瓜、芭樂（在地、價廉）

## 六、調整策略 — 不破壞核心 stack 的升級

### 原則
1. **不剔除任何現有 stack**（蛋、優格、地瓜、菇、亞麻、南瓜籽、橄欖油全部維持）
2. **新增 high-ANDI 項目填補晚餐 + 配菜 + 點心空缺**
3. **輪替 > 固定**（多樣性勝過單一高分）
4. **一次只新增 1-2 樣**（觀察接受度）

### 一週升級 menu 模板

```
週一  晚餐：燙地瓜葉 100g + 燙青花菜 100g + 主菜
      點心：南瓜籽 + 1 顆奇異果

週二  晚餐：青江菜 100g + 紅蘿蔔絲拌沙拉 + 主菜
      點心：南瓜籽 + 1/2 顆酪梨（薄塗全麥麵包）

週三  晚餐：菠菜湯（菠菜 100g + 豆腐 + 蛋花）+ 主菜
      點心：南瓜籽 + 莓果輪替（草莓/覆盆莓）

週四  晚餐：羽衣甘藍按摩沙拉（嫩 kale 100g）+ 主菜
      點心：南瓜籽 + 蘋果

週五  晚餐：青花菜 100g + 番茄燉煮 + 主菜
      點心：南瓜籽 + 黑巧 10g + 桑椹

週六  晚餐：扁豆咖哩 + 高麗菜 + 主菜
      點心：南瓜籽 + 1 顆芭樂

週日  晚餐：西洋菜湯（西洋菜 100g + 蛋 + 薑）+ 球芽甘藍 + 主菜
      點心：青花菜苗 50g 拌飯 🆕 sulforaphane 王炸日
```

## 八、ANDI 之外的「全方位飲食指標」（更完整框架）

ANDI 是一個視角，配合其他指標看才完整：

| 指標 | 內容 | 對你關聯 |
|------|------|---------|
| **NOVA 加工分級** | 未加工 → 超加工 | 你已避超加工 |
| **DII（Dietary Inflammatory Index）** | 食物發炎指數 | 你已偏抗發炎 |
| **MIND diet score** | 認知保護飲食 | 莓果 + 綠葉 + 橄欖油重疊 |
| **DASH score** | 降 BP 飲食 | 你目標一致 |
| **HEI（Healthy Eating Index）** | 美國 USDA 指標 | 一般參考 |
| **Mediterranean Adherence Score** | 地中海依從度 | 你高分（橄欖油、魚油、堅果、莓果）|

## 十、台灣便當配菜現實 — 結構性 gap 與突破方案

**標準便當的「配菜」幾乎全是淺色或非葉菜**，深綠葉量遠低於需求。這是台灣外食族的結構性 gap，不是個人選擇問題。

### 台灣便當常見配菜的 ANDI 真實值

| 常見配菜 | ANDI 估計 | 深綠葉？| 真實營養值 |
|---------|----------|--------|-----------|
| 高麗菜炒 / 滷 | ~ 481 | ❌ 淺綠 | 煮後分量被壓縮、油 + 鈉拉低營養比 |
| 蘿蔔絲 | ~ 100 | ❌ | 鈉量大 |
| 玉米筍 | ~ 90 | ❌ | 微量 |
| 紅蘿蔔絲 | 458 | ❌ 橘 | 量極少（1-2 片） |
| 小黃瓜 | 60-80 | ❌ | 水分多 |
| 滷蛋 | 34 | — | 蛋白 |
| 豆乾 / 滷豆腐 | 35-40 | — | 蛋白 |
| 醃漬物（雪裡紅、酸菜） | ~ 100 | ❌ | **鈉炸彈** |
| 涼拌四季豆 | ~ 200 | 🟡 中綠 | OK |
| 滷海帶 | ~ 150 | 🟢 海菜 | OK |
| **燙青菜（另點）** | **300-700** | ✅ **深綠** | **黃金選項** |

→ **一個標準便當的深綠葉攝取量估 < 30 g**，距離 WHO/Fuhrman 200-250 g 目標**差 7-8 倍**。

### 常見台灣深綠葉 ANDI 對標

| 菜 | ANDI 估計 | 鉀（mg/100g 熟）| 葉酸 | 草酸 | Tier |
|----|----------|----------------|------|------|------|
| **菠菜** | **707**（Fuhrman 列）| 466-558 | 高 | **高**（腎鈣化點史注意） | Tier A |
| **地瓜葉**（番薯葉）| ~ **500-600**（亞洲研究推估） | 320 | 高 | 中 | Tier A，亞洲在地之王 |
| **空心菜**（蕹菜）| ~ **400-500**（推估）| 308 | 中 | 中-高 | Tier B-A |
| 青江菜（小白菜）| 865 | 252 | 中 | 低 | Tier S |
| 龍鬚菜 | ~ 300 | 300 | 中 | 低 | Tier B |
| 過貓（食用蕨）| ~ 350 | 350 | 中 | 低 | Tier B |
| A 菜 / 萵苣 | ~ 250 | 200 | 中 | 低 | Tier C-B |

**註**：地瓜葉與空心菜未在 Fuhrman 官方 ANDI 表（美國市場較不普及），但根據台大食科系與農委會資料庫的營養分析，這兩者**葉黃素、polyphenol、Vit K1、葉酸、鉀**都在世界級綠葉行列；地瓜葉多項台灣本土研究指出抗氧化能力可與 kale 平起平坐。

→ **常見台灣深綠葉完全對標世界級 Tier S-A**，問題不是「選錯菜」，是「便當提供的量太少」。

### 為什麼台灣便當綠葉這麼少（結構性原因）

| 因素 | 結果 |
|------|------|
| **成本** | 深綠葉成本高（保存差、損耗大）→ 業者用便宜耐放的高麗菜、蘿蔔 |
| **保存** | 深綠葉 4 小時就萎黃 → 不適合早備、下午賣 |
| **口味** | 多數客人認為深綠葉「不好吃」→ 業者偏好甜的高麗菜 |
| **賣相** | 燙過深綠葉看起來「縮水」、賣相差 |
| **習慣** | 台灣便當文化「飯 + 主菜 + 3 配菜」的「配菜」傳統就是醃滷類 |

→ **不是業者壞，是市場結構決定的**。需主動突破。

### 四種突破方案（依執行難度排）

#### 方案 1：便當 **另加一份燙青菜**（最有效，門檻最低）⭐

```
便當（你原本選的）NT$ 80-120
+ 燙青菜一份（地瓜葉 / 空心菜 / 菠菜 / 青江菜輪替）NT$ 25-40
→ 總 NT$ 105-160

額外獲得：
  深綠葉 100-150g（一份）
  鉀 ~ 350-500 mg
  葉黃素 / 玉米黃素 / K1 大幅補上
  該餐 ANDI 加權 從 ~ 100-130 → ~ 250-300
```

**紀律**：
- ✅ 選**燙**青菜而非炒（油 + 鈉少很多）
- ✅ 醬汁（醬油膏、肉燥汁）**請另放或直接不要**（鈉源）
- ✅ 蒜末 OK，加分（GBOMBS 中的 O）
- ✅ 若有蠔油 → 少量（鈉 870 mg / 茶匙）

#### 方案 2：選 **自助餐 / 簡餐** 而非便當
- 自助餐可自由夾菜 → 一次 2-3 種深綠葉
- 簡餐多附燙青菜或沙拉
- 健康風 lifestyle 餐廳（咖哩、定食）綠葉比例較高

**台灣常見可選**：
- 自助餐（永和豆漿、銀座、八方雲集旁的菜飯店、台菜自助餐）
- Subway（沙拉碗）
- Cocomart 蔬食
- 7-11 沙拉碗（雞胸 + 蔬菜）

#### 方案 3：**自帶綠葉「補充包」**

```
週日備餐（30 分鐘）：
  地瓜葉 / 菠菜 / 青江菜 / 青花菜 各 200g 燙熟
  → 分裝 4 個密封盒（每盒 ~ 150g）
  → 週一至週五帶到辦公室冰箱
  → 午餐時取一盒微波 1 分鐘加入便當

週五備一次、撐 5 天
```

優點：完全可控、鈉低、品質高
缺點：要備餐意願 + 辦公室冰箱

#### 方案 4（緊急 backup）：**7-11 蔬菜小包**
- 7-11「滷青菜」、「燙青菜小包」、「沙拉碗」
- 鈉略高（300-500 mg/包）但比沒有好
- 一包 NT$ 25-40

### 對 Stack 的具體推進

**Phase 1（本週起）**：便當外加燙青菜
- 每次點便當固定 + 燙青菜（不接受替代）
- 輪替：地瓜葉、空心菜、菠菜、青江菜、龍鬚菜、過貓
- 醬油膏 / 肉燥汁不要

**Phase 2（2 週後）**：晚餐自家補綠葉 100g
- 即使午餐已加，晚餐家裡仍煮 100g 燙青菜或炒（蒜 + 橄欖油）
- 達 WHO/Fuhrman 250g 綠葉/天 目標

**Phase 3（1 個月後）**：輪替深度進階
- 一週 1 次青花菜苗（sulforaphane 王）
- 一週 2-3 次十字花科（青花菜、白花菜、芥藍、高麗菜）
- 一週 1 次西洋菜湯（湯品輕鬆 cover）

### 預期 ANDI 加權變化

```
現狀（便當無加燙青菜）：
  午餐 ANDI ~ 100-130
  每日加權平均 ~ 175

方案 1（便當 + 燙青菜）：
  午餐 ANDI 升至 ~ 250-300
  每日加權平均升至 ~ 220

方案 1 + 晚餐再補 100g 綠葉：
  每日加權平均 ~ 260-290（接近 Fuhrman 推薦 ≥ 300 目標）
```

✅ 蛋（34）、優格（28）、WPI、橄欖油（9）、香蕉（30）、黑巧（70）  
原因：營養 / 蛋白 / 益生菌 / 健康脂無可替代

### 主要 Gap（升級空間最大）
🟡 綠葉量不足（升級：100g → 250g/天，輪替 5+ 種）  
🟡 十字花科缺席（升級：青花菜 3 次/週 + 青花菜苗 1 次/週）  
🟡 多色蔬不足（紅彩椒、紅蘿蔔、番茄）  
🟡 全豆缺席（一週 2 次加入）  
🟡 洋蔥類缺席（一週 2-3 次加入）  
🟡 莓果單一（藍莓以外輪替）  

### 不該加的（誤判風險）
❌ 為高 ANDI 棄蛋 → 失 choline + lutein  
❌ 為高 ANDI 棄魚油 → 失 EPA/DHA  
❌ 為高 ANDI 棄堅果 / 酪梨 → 失健康脂  
❌ 為高 ANDI 棄優格 → 失 probiotic + 鈣  
❌ 把所有點心換成生菜 → 飽足、心理可持續性差
