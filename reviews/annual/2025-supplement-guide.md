# 補充品與茶飲指南 — 2025 健檢後版本

**基準日期：** 2025-09-17 健檢結果
**優先指標：** LDL 177 / 總膽固醇 234 / 尿酸 8.6 / HbA1c 6.0% / hsCRP 0.302 / 脂肪肝（新增）
**最後更新：** 2026-04-04（PubMed RCT 全面查證，5 個平行 agent；新增抹茶執行方案）

---

## 一、茶飲選擇（C4 取 2）

> 選擇原則：最大覆蓋面、最小重疊

| 茶飲 | 選擇 | 理由 |
|------|------|------|
| **抹茶** | ✅ 推薦 | LDL、總膽固醇 RCT 最強（⭐⭐⭐），是非藥物降膽固醇的核心選項 |
| **枸杞茶** | ✅ 升格推薦 | TG⭐⭐⭐（兩篇獨立 meta-analysis 確認），且 HbA1c 有 RCT 支持 |
| 玉米鬚茶 | ☐ 次選（降級） | 尿酸原評⭐⭐⭐，但 PubMed 查無人體 RCT；血壓降為⭐⭐；LDL/TC 有 RCT 但品質低 |
| 牛蒡茶 | ☐ 次選（降級） | 幾乎全為動物/體外研究；唯一 RCT 與運動混淆；暫不優先 |

> **注意：** 玉米鬚茶的「尿酸⭐⭐⭐」評級已根據 PubMed 查無人體 RCT 降為「—」，詳見下表。

---

## 二、補品組合（互補性最簡方案）

> 選擇原則：已有項目填 TG/hsCRP/尿酸，缺口在 LDL、血壓、維生素 D、睡眠

| 補品 | 狀態 | 優先 | 互補邏輯 |
|------|------|------|---------|
| **魚油 ×4** | ✅ 已有 | 必留 | TG⭐⭐⭐、脂肪肝⭐⭐⭐（升級）、血壓⭐⭐⭐（升級），無可替代 |
| **酸櫻桃膠囊** | ✅ 已有 | 必留 | 尿酸⭐⭐⭐（升級）+ 血壓⭐⭐⭐（新發現）|
| **D3K2** | ➕ 新增 | 🔴 必加 | 修正維生素 D 28.8；hsCRP⭐⭐⭐、血壓⭐⭐⭐（均升級） |
| **鎂（甘胺酸鎂）** | ➕ 新增 | 🔴 必加 | 血壓⭐⭐⭐ + 睡眠改善，睡眠是你的最大弱點 |
| **益生菌** | ➕ 新增 | 🟠 建議 | LDL⭐⭐⭐（升級）+ hsCRP⭐⭐⭐（升級），比原評估更強 |

**最簡核心組合（5 項）：** 魚油 + 酸櫻桃 + D3K2 + 鎂 + 益生菌

## 四、各指標最強覆蓋項目（更新）

- **LDL / 總膽固醇：** 抹茶⭐⭐⭐ + 益生菌⭐⭐⭐
- **TG：** 魚油⭐⭐⭐ + 枸杞茶⭐⭐⭐
- **尿酸：** 酸櫻桃⭐⭐⭐
- **血壓：** 鎂⭐⭐⭐ + 酸櫻桃⭐⭐⭐ + 魚油⭐⭐⭐ + D3K2⭐⭐⭐
- **hsCRP：** 益生菌⭐⭐⭐ + D3K2⭐⭐⭐
- **脂肪肝：** 魚油⭐⭐⭐ + 抹茶⭐⭐
- **HbA1c：** 鎂⭐⭐ + 益生菌⭐⭐ + D3K2⭐⭐

| 時段 | 執行 | EGCG |

| 早餐 | 伊藤園抹茶粉 2.4g 拌入優格 | ~57–79mg |

> **膠囊注意事項：** 你有脂肪肝，膠囊必須隨含油脂的餐後服用，不可空腹。每天 1 顆（~200mg EGCG），不超過 2 顆，避免肝臟負擔。

## 八、預期效果與時程

| 時間 | 可能看到的改善 |
|------|--------------|
| 4–6 週 | TG 下降、血壓穩定（魚油+鎂+酸櫻桃三重覆蓋） |
| 8–12 週 | 尿酸開始明顯下降（酸櫻桃 RCT 支持）、維生素 D 達標 |
| 3 個月 | LDL 改善（抹茶+益生菌）、HbA1c 可見改善 |
| 3 個月後 | 根據 LDL 落點決定是否討論 statin |

**誠實的預期上限（無 statin）：**
- LDL：177 → 約 152–162（抹茶 −4–5% + 益生菌 −3–8%，效果可疊加）
- 總膽固醇：234 → 約 204–214
- 尿酸：8.6 → 約 6.5–7.5（酸櫻桃 RCT 證據比玉米鬚茶更可靠）
- hsCRP：0.302 → 低於 0.300（益生菌+D3K2 組合，最容易達標）
