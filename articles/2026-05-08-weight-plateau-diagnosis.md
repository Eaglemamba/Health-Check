# 體重平台期診斷與飲食調整方案 — 2026-05-08

**觸發脈絡**：W19（5/3–5/8）體重停在 68.1–68.2 kg，相對 W18 低點 67.8 kg 感覺停滯；BB 起床連 5 天 < 50；大腿酸感無運動仍持續 ≥ 5 天。

**結論先行**：不是平台期，不是吃太多，**是赤字過大 + 步數短缺 + 乳糖負荷 + VitD 不足**的系統性恢復不良。

## 二、滯水 vs 脂肪：判決

### ❌ 推翻「脂肪太多」
- 全日 1,425–1,600 kcal vs TDEE ~2,200–2,400 → **真實赤字 640–1,000 kcal/日 = 0.6–1.0 kg 脂肪/週**
- 內臟脂肪等級 9.5 連 7 天持平 → 脂肪未堆積
- 體脂率 19.3 → 20.3% 跟飲水量強相關 → BIA 脫水假象

### ❌ 推翻「鈉滯水」
- 全日 1,430–1,830 mg，遠低於 2,300 mg 標準
- 4/22 那種高鈉模式（單餐剝皮辣椒雞胸 800–1,000 mg）不是常態

### ✅ 真正嫌疑（按證據強度）

| # | 因素 | 量級 | 證據 |
|---|---|---|---|
| 1 | **步數短缺 W19**（雨天從 13,475 降至 ~8,000） | 0.6–1.2 kg「該降沒降」 | ★★★★★ |
| 2 | **熱量赤字過大引發 cortisol 滯水**（BB 連 5 天 < 50 印證） | 0.5–1 kg | ★★★★★ |
| 3 | **VitD 不足**（D3K2 從 3000 降至 2000 IU） | 大腿酸感主嫌 | ★★★★ |
| 4 | **乳糖負荷過量**（全日 40–56g vs 耐受 25g） | 0.3–0.7 kg 腸道滯水 + 礦物質吸收干擾 | ★★★★ |
| 5 | **OSA 間歇性缺氧** | 肌肉修復受損 | ★★★ |
| 6 | **無雞胸日蛋白質 85g 不足** | 肌肉自食 | ★★★ |

## 三、反直覺結論：需要**多吃**，不是少吃

> 體重停滯 + BB 持續低 + 體脂率讀數浮動 + 大赤字 + 大腿酸無運動 = **代謝適應前兆**

身體偵測到熱量短缺 → 拉高 cortisol 保水分、降基代、肌肉自食。**這時節食只會更卡。**

## 四、修訂後行動清單

### 立即（今晚就做）
1. **D3K2 補回 3,000 IU**（早餐隨脂肪餐）
2. **鎂 400 mg 睡前**（確認沒漏吃）
3. **椰子水 1 罐 (~330ml) + 鹽 1g**（補電解質）
4. **21:30 強制就寢**（連 7 天）

### 飲食調整（本週開始）
| 變動 | 原因 |
|---|---|
| 熱量上修至 **1,700–1,800 kcal** | 解赤字過大、cortisol 滯水 |
| 無雞胸日晚餐補 **蛋花湯 1 碗或豆腐半盒**（+15g 蛋白質） | 蛋白質保底 ≥ 95g |
| 早餐去羊奶 + 乳清改用水沖 + 加 **1 顆水煮蛋** | 早餐乳糖從 14g → 6g |
| 抹茶牛奶改 **lactose-free 奶 300ml** | 午餐乳糖從 14g → 0 |
| 點心牛奶每日 **≤ 1 杯**，挪到早上 | 控全日乳糖 ≤ 25g |
| 雞胸選**清蒸 / 舒肥原味**（鈉 ~75–400 mg） | 避免高鈉款 |

### 運動調整
- **3 天內取消任何中強度以上運動**，只走路
- **雨天用室內補位 SOP**（已寫入 `templates/pt-rules.md`）
- 雨天硬底線：每日 ≥ 8,000 步

### 醫療追蹤
- **PSG 預約落地**（OSA 是上游，本週首要任務）
- 下次抽血加項：**25(OH)D + 早晨 cortisol + CK**（排除 statin / 肌炎）
- **大腿酸感若 7 天內未消** → 物理治療師評估（觸發 pt-rules.md 5 天規則）
