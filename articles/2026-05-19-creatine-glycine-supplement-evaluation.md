# Daily Supplement 加入評估：Creatine + Glycine

**日期**：2026-05-19
**對象**：David Kuo
**問題**：是否將 **creatine（肌酸）** 與 **glycine（甘胺酸）** 納入或維持於 daily supplement stack
**當前 stack 基準**：`articles/2026-03-25-supplement-guide.md` v2（2026-05-11 更新版）
**現況**：
- Glycine 3g 睡前 — **已在 v2 stack 核心 6 項**（2026-05-11 納入）
- Creatine — **未列入** v2 stack（僅在「條件性」候選與未來探索清單外圍）

## 一、執行摘要

| 補品 | 現狀 | 建議 | 主因 |
|------|------|------|------|
| **Glycine 3g 睡前** | ✅ 已在 stack | **維持** | RCT 級證據（Yamadera 2007）、三軸機制（核心降溫 + NMDA + 腦幹）、與你的 wide-range latency 問題對應、與既有鎂 / 酸櫻桃機制互補 |
| **Creatine monohydrate 3g 早餐後** | ❌ 未列入 | **🟡 條件性加入（裕度收窄）** | 認知韌性 + 肌肉抗老化效益強；**但 2026-03-25 baseline creatinine 1.05 mg/dL 已偏中段**，3g 預期推升至 1.15-1.35，距 1.4 上限裕度有限 — 須**腎臟科轉診先完成 + 嚴格 washout 7 天** |

**唯一警示**：creatine 會讓 **血清 creatinine 數值生理性升高 0.1-0.3 mg/dL**（並非腎損傷，但會干擾健檢解讀）— 抽血前 5-7 天停用即可。**不影響尿酸數值**。

## 二、Glycine — 證據再確認

### 2.1 已在 stack，無需重新評估

詳細機轉與 RCT 證據已記錄於 `articles/2026-03-25-supplement-guide.md`（2026-05-11 v2）第七節。本評估僅做一致性確認。

| 項目 | 內容 |
|------|------|
| 劑量 | 3g 純粉睡前（21:00） |
| 機轉 | 核心體溫下降（Inagawa 2006）+ NMDA GluN2C/D 抑制 thalamocortical（Bannai 2012）+ 腦幹 glycinergic 肌肉放鬆（Chase 1989） |
| 主要證據 | Yamadera 2007 RCT（n=23 失眠者，3g 睡前，主觀 latency ↓ 50%、深眠 ↑、次日疲勞 ↓） |
| 與你現有 stack | 與鎂（GABA-A）與酸櫻桃（melatonin）三條獨立軸線並行 |
| 監測項 | 主觀 latency、Garmin estimated latency（特別是 wide_range 比例） |

### 2.2 是否需調整？

**否**。3g 為 RCT 證實有效劑量，下調至 1.5g 為起步耐受期（已於 2026-05-11 完成）；上調至 5g 沒有額外效益（NMDA glycine site 在 plasma 1000-1500 µmol/L 已飽和）。**維持原劑量**。

### 2.3 補充：Glycine 是 creatine 的內源前驅物

人體 50% 的內源 creatine 由甘胺酸（glycine）+ 精胺酸（arginine）+ S-adenosyl methionine 合成，主要在肝、腎、胰臟。**這意味補 glycine 同時微弱支持 creatine 內源生成**，與外源補 creatine 不衝突而是協同。

## 三、Creatine — 詳細評估

### 3.1 證據基線（依與你個人指標的相關性排序）

#### 3.1.1 睡眠剝奪下的認知保護（高度相關）⭐⭐⭐

你 TST 連續 5-6 小時，遠低於 7-9 小時建議區間。Creatine 對「短睡眠 / 睡眠剝奪」狀態下的認知功能有獨特效益：

- **Gordji-Nejad et al. 2024, Scientific Reports**（[Nature SR](https://www.nature.com/articles/s41598-024-54249-9)，n=29，21 小時睡眠剝奪 + 0.2 g/kg 單劑 creatine monohydrate）
  - **腦部高能磷酸（PCr / ATP）穩定維持**
  - 工作記憶與處理速度顯著保留
  - 認知衰退顯著低於對照組
- **Hapres JPBS 2024** 系統性回顧：creatine 對腦部 bioenergetics 在能量需求高（睡眠剝奪、低氧、年齡）狀態下效益最大

**意義**：你正在用工作日 ~5h 的 TST 應付管理 + 育兒 + 健康追蹤，**creatine 是有 RCT 證據的認知韌性 buffer**。

#### 3.1.2 中年肌肉與骨密度保留（高度相關）⭐⭐⭐

你 mid-40s + 身體脂肪 19.6% + 開始跑步 4/26：

- **2024-2025 meta-analyses（[PMC12752335](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12752335/)、[Frontiers Physiology 2024](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2024.1496544/full)）**：
  - Creatine + resistance training（≥ 2x/week）→ 顯著提升肌力 + 瘦肉量
  - 65 歲以下中年男性效益已可觀
  - 對 sarcopenia 預防有 RCT 證據
- **[PMC6518405](https://pmc.ncbi.nlm.nih.gov/articles/PMC6518405/)** 系統性回顧：跌倒預防 + 抗發炎輔助

**意義**：你的 v2 supplement-guide §10 已寫入阻力訓練 protocol（2026-04-21 加入，為 HDL 39 → ≥45 的主力槓桿）。**creatine 是該 protocol 的天然搭檔**。

#### 3.1.3 心血管 / 血壓 / HRV（中度相關）⭐⭐

- 對血壓的直接影響：中性。某些小型 trial 顯示 creatine 在高劑量（10g+）短期可能輕微升 SBP 1-2 mmHg（水分滯留機制），但 3-5g 維持劑量無顯著影響
- 對 HRV 的直接影響：證據稀少。間接：認知資源保留 → 自主神經負荷下降 → 可能微正面
- 不是 HRV 主力介入（共振呼吸 / OSA 治療 / Omega-3 才是）

#### 3.1.4 跑步表現（負相關，需注意）⭐

- **2021 meta-analysis（[Critical Reviews Food Science & Nutrition](https://www.tandfonline.com/doi/abs/10.1080/10408398.2021.2008864)）**：creatine **不提升 VO2max**
- **負面效應**：creatine 引起 1-2 kg 水分滯留（細胞內水合，非水腫）。在跑步（負重運動）中，**體重增加直接拖累配速效率**
- 對短時高強度間歇（HIIT）有微正面效益；對 Zone 2 中性偏負

**意義**：你目前是 Couch-to-5K 第 1-3 週 Z2 為主。Creatine 短期（前 2-3 週）可能讓 RPE 略升、配速略慢。**這是已知 trade-off**。8 週後身體適應，影響趨平。

### 3.2 安全性（對你的 baseline 特別核對）

#### 3.2.1 尿酸 — 不影響 ⚠️ 但需澄清誤解

| 物質 | 代謝路徑 | 終產物 |
|------|----------|--------|
| **Creatine**（補充） | 磷酸化儲存於肌肉 → ATP 緩衝 → 部分轉為 **creatinine** | Creatinine（與尿酸完全不同分子）|
| **Purines**（嘌呤）| Xanthine → uric acid | **Uric acid（尿酸）** |

- **Creatine 不含嘌呤** → 不進入 xanthine oxidase 路徑 → **不產生尿酸**
- 動物研究（[Sciencedirect 2017](https://www.sciencedirect.com/science/article/abs/pii/S0006291X17310392)）甚至顯示 taurine（牛磺酸）抑制 xanthine oxidase 而降尿酸，但這是不同分子，與 creatine 無關
- **臨床安全綜論**（[BUBS Naturals review](https://www.bubsnaturals.com/blogs/creatine-and-fitness/creatine-monohydrate-and-uric-acid-what-active-lifestyles-need-to-know)）：normal dosing 不引發 hyperuricemia 或 gout 事件

**對你（UA 8.9 mg/dL，已戒果糖、待腎臟科轉診）**：creatine 不是禁忌。但**抽血前 5-7 天停用**以避免 creatinine 干擾解讀（見下）。

#### 3.2.2 血清 Creatinine — 會生理性升高（重要）

- **Creatine → Creatinine** 是正常代謝終產物
- 每日攝取 3-5g creatine → 血清 creatinine 可升高 **0.1-0.3 mg/dL**（從 0.9 升至 1.0-1.2 mg/dL 區間）
- **這不是腎損傷**，是補充物本身的代謝物增量
- 但**會干擾健檢解讀**：eGFR 用 creatinine 計算 → eGFR 數字略降，可能被誤判為 CKD
- **解法**：健檢前 5-7 天停用，washout 期 creatinine 回到 baseline
- **你 2026-03-25 baseline creatinine：1.05 mg/dL**（BUN 14）— 已落在正常上半（0.7-1.2）。3g creatine 預期升至 1.15-1.35。**接近 1.4 上限，安全裕度有限** → 健檢前 7 天 washout 必須嚴格執行；若你後續腎臟科 baseline 顯示 creatinine 已升至 ≥ 1.2 baseline，creatine 啟動需重新評估

#### 3.2.3 腎功能 — 長期安全性已建立

- 5 年追蹤研究（健康受試者）：3-5g/天無腎功能損害
- **慢性腎臟病（CKD）患者除外**：你尚未診斷 CKD，但腎臟科轉診待安排，**建議轉診後再啟動**為穩妥順序

#### 3.2.4 體重增加 — 與減重目標衝突

- 開始 creatine 後 2-4 週體重增 1-2 kg（細胞內水合）
- **對你（目標 68 → 65 kg）造成短期心理干擾** — 看到體重數字反彈可能誤判為復胖
- **解法**：啟動 creatine 同時於 daily.md 註記「creatine 啟動日 = X/X」，2-4 週體重數字加 1.5 kg 為基準調整
- 體脂率與內臟脂肪等級**不受 creatine 直接影響**（水分滯留不算脂肪）→ 這兩個指標更可靠

### 3.3 與 Glycine 的關係

| 項目 | Glycine（已在 stack） | Creatine（評估中） |
|------|------------------------|--------------------|
| 機制重疊？ | ❌ 完全獨立 | — |
| 內源生成關係 | 是 creatine 的合成前驅物 | — |
| 服用時段 | 睡前 21:00 | 早餐後 06:30（不衝突） |
| 安全交互作用 | 無 | — |

**結論**：兩者並用無衝突，反而 glycine 微弱支持內源 creatine 生成，**屬於協同層級**。

## 四、決策建議

### 4.1 Glycine：**維持 3g 睡前**

無需異動。已於 2026-03-25 supplement-guide v2 第七節完整收錄。

### 4.2 Creatine：**🟢 條件性加入**

#### 啟動條件（先做完再啟動，順序重要）

- [ ] 確認近期健檢 baseline creatinine（查 `reviews/annual/2026-03-25-pe.json`）
- [ ] **腎臟科轉診完成**（你的 v2 supplement-guide pending item）
- [ ] 確認 PSG 已預約或完成（避免新增變數混淆 OSA 介入判讀）

上述任一未完成 → 暫緩，**先處理優先級更高的項目**。

#### 啟動 protocol（條件滿足後）

| 參數 | 規格 |
|------|------|
| 形式 | Creatine monohydrate（粉，USP grade）|
| 劑量 | **3g/天**（不做 loading phase，5g/天非必要） |
| 時段 | 早餐後 06:30 隨水或優格服用 |
| Loading | **跳過**（loading phase 體重增加更明顯，長期效益相同） |
| 品牌 | Now Foods / Thorne / Optimum Nutrition / BulkSupplements（任一 USP grade） |
| 月成本 | 約 150-250 TWD |
| Washout（健檢前）| **抽血前 5-7 天停用** |
| 持續時間 | 8 週試行 → 評估後決定長期 |

#### 8 週評估指標

| 指標 | 預期變化 | 判讀 |
|------|----------|------|
| 體重 | +1-2 kg（前 2-4 週）| 預期反應，非復胖 |
| 體脂率 | 持平或微降 | 真正體組成方向指標 |
| 跑步配速（同 HR）| 前 2 週可能 +5-10 sec/km | 預期，4 週後適應 |
| 阻力訓練 1RM | +5-15% | 主要效益指標 |
| 主觀認知韌性（疲倦日 PVT 自評）| 改善 | 主要次要效益 |
| 血清 creatinine（健檢時，停藥 7 天後） | 無變化 | 確認非腎損傷 |
| 血清 UA（健檢時）| 無變化 | 確認非新增風險 |
| HRV Deep 期均值 | 無顯著變化 | 不是 HRV 主力介入 |

#### 停止條件

任一發生 → 停用 + 醫療評估：

- 任何 unexplained 腎功能異常訊號（停藥 7 天後 creatinine 仍 > 1.3 mg/dL）
- 主觀肌肉抽筋頻率上升（hydration 不足訊號）
- 跑步表現 4 週後仍未恢復至 baseline
- 開始任何新藥物前重新評估（特別是 NSAIDs、ACE inhibitors）

## 六、底線結論

1. **Glycine 維持原劑量** — 無需異動
2. **Creatine 條件性加入（裕度收窄判讀）** — baseline creatinine 1.05 已偏中段，啟動**必須**先完成：(a) 腎臟科轉診（取得正式 baseline + 醫師認可）、(b) PSG 預約敲定（避免變數混淆）、(c) 同意 healthcheck 前 7 天嚴格 washout SOP
3. **若啟動，採 3g monohydrate 早餐後、不做 loading**
4. **體重短期 +1-2 kg 為預期反應**，以體脂率與 VFL 為真實體組成指標
5. **健檢前 5-7 天停用**，避免 creatinine 干擾解讀
6. **8 週評估**重點：阻力訓練 1RM 提升、認知韌性自評、配速恢復至 baseline

主要效益靶點與 OSA / HRV / 血壓 等核心問題**正交**（不互相搶資源、不互相牴觸），是低風險中收益的增益層。但**不應在 PSG / 腎臟科轉診兩件高優先事項完成前啟動**，避免新變數混淆診斷判讀。
