## 四、各指標策略分析

| 指標 | 最強覆蓋 | 策略評估 |
|------|---------|---------|
| **LDL / 總膽固醇** | 抹茶⭐⭐⭐ + 益生菌⭐⭐⭐ | LDL 177 → **154**（已降 23，達原預測區間 154–165）；TC 234 → **191**（🟢 已達標）；**LDL 仍高於目標 130**，3 個月後（~2026-07）複測決定是否討論 statin |
| **TG** | 魚油⭐⭐⭐ + 枸杞茶⭐⭐⭐ | TG 125 → **103**（🟢 穩定在正常區），魚油策略繼續維持即可 |
| **尿酸** | 酸櫻桃⭐⭐⭐（孤立） | 8.6 → **8.9（惡化 +0.3）**；已屬體質性（26 歲即 7.8），補充品 / 飲食介入難以根治；**建議腎臟科評估 febuxostat / allopurinol** |
| **血壓** | 鎂 + 酸櫻桃 + 魚油 + D3K2（均⭐⭐⭐） | 本次健檢 **153/88 🔴**（含睡眠剝奪干擾），家中均值約 125；需**居家連測 2 週確認**；若均值 >135/85 應考慮起始降壓藥 |
| **hsCRP** | 益生菌⭐⭐⭐ + D3K2⭐⭐⭐ | **3.02 → 1.42 mg/L（−53% 🟡）**：AHA high → moderate，原「跨過 0.300」目標已達；4 年連續改善（24.01 → 5.61 → 3.02 → 1.42） |
| **脂肪肝** | 魚油⭐⭐⭐ + 抹茶⭐⭐ | 2026 腹超未做；ALT 改善（25→22）間接支持脂肪肝部分退縮（體脂 −3.4%）；AST 從 27→38 需追蹤（FIB-4 = 0.96 仍低風險） |
| **HbA1c** | 鎂⭐⭐ + 益生菌⭐⭐ + D3K2⭐⭐ | 6.0% → **5.9%**（prediabetes 平台期鬆動）；仍屬 prediabetes，飲食和運動效果仍是所有補充品加總的數倍 |
| **HDL 🆕** | 運動 + 健康脂肪（補充品效果有限）| 46 → **39 🟠**（<40 為 ATP III 定義的 low HDL）；**減脂 trade-off 警訊**；需 150 min/週中強度有氧 + 橄欖油 + 堅果 30g/日 + 魚油 EPA/DHA；**不建議 niacin**（RCT 未降事件） |

## 五、抹茶執行方案（2026-04-04 確定）

### 產品選擇

| 產品 | 規格 | 每天成本 | EGCG/天 | 備註 |
|------|------|---------|---------|------|
| **伊藤園 Oi Ocha 濃抹茶粉** | 80g / 359 TWD | ~33 TWD | 57–79mg（2.4g） | 機能性表示食品，體脂肪官方認證 |
| **NOW Foods EGCG 膠囊** | 400mg / 180顆 / 765 TWD | ~4.25 TWD | ~200mg（1顆） | iHerb 購入；需隨含油脂餐服用 |
| **組合方案（建議）** | 兩者並用 | ~37 TWD | **270–320mg** | 進入 RCT 有效範圍中段 |

### 每日執行

| 時段 | 執行 | EGCG |
|------|------|------|
| 早餐 | 伊藤園抹茶粉 2.4g 拌入優格 | ~57–79mg |
| 午餐後 | NOW EGCG 膠囊 1 顆（隨餐，需含油脂） | ~200mg |
| **合計** | | **~270–320mg/天** |

> **膠囊注意事項：** 你有脂肪肝，膠囊必須隨含油脂的餐後服用，不可空腹。每天 1 顆（~200mg EGCG），不超過 2 顆，避免肝臟負擔。
>
> **抹茶 + 優格的協同：** 優格蛋白質/脂肪幫助 EGCG 吸收，益生菌與 EGCG 同時攝取可能有腸道協同效果。

### 下一階段（2026-03 → 2026-07 複測）目標

| 時間 | 目標 |
|------|------|
| 4–6 週 | **HDL 救援**方向性逆轉（有氧 + 健康脂肪），BP 居家測量均值確認 |
| 8–12 週 | LDL 進一步降至 130–140；HDL > 40 |
| 3 個月（7 月）| 複測 LDL：若仍 > 150 且 HDL < 40 → 與醫師討論 statin；若 < 140 可續保守 |
| 同時 | **腎臟科評估尿酸**（已體質性，補品無法根治）|

**誠實的預期上限（無 statin，從 2026-03-25 基準起）：**
- LDL：154 → 約 140–150（抹茶 + 益生菌 + psyllium 疊加可再 −5–8%）
- HDL：39 → > 40（有氧 150 min/週 + 堅果 30g/日 為核心槓桿）
- 尿酸：**補充品已到天花板**，必要時轉藥物介入
- hsCRP：1.42 mg/L → 目標維持 < 2.0（已達 moderate，再降需更大體重減幅）
