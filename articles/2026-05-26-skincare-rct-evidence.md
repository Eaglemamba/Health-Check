# 護膚 practice 的 RCT 證據 + 台灣選品指南 — 2026-05-26

*非每日 check-in。本篇整理「痘痘減少後、膚況仍不適」情境下，各護膚 practice 的 RCT 等級證據、台灣可取得品項與疊加時序。所有醫療文獻引用自 PubMed，DOI 內嵌。*
*Copilot 模式：本篇為建議整理；口服藥物（如口服傳明酸）須經皮膚科醫師評估後決定，非自行用藥依據。*

---

## 核心判讀：膚況「不適」≠ 做得不夠

痘痘少了卻不適（泛紅、緊繃、刺痛、脫屑、上品就辣），最常見的原因是**屏障受損 / 活性成分刺激**（早C晚A 刺激 + 每天卸妝油過度清潔），而非缺少產品。
→ 優先補「地基層」，療效層按耐受加頻，不是再疊更多酸/A。

---

## 三層架構（按優先序）

```
地基層（每天，非協商）      防曬 + 保濕            ← 屏障與抗老地基
療效層（按耐受加頻）        早C / 晚A            ← 抗光老化、細紋、膚質
色素層（痘印/斑點階段）     外用/口服傳明酸、C、A   ← 處理 PIH / 肝斑
飲食（全身性輔助）          低升糖負荷            ← 痘痘 + 代謝
```

---

## Part 1 — 地基層

### 防曬（最高證據、最高優先）
- Nambour RCT，903 人、4.5 年：每日防曬組皮膚老化比「需要才擦」組少 **24%**（OR 0.76, 95%CI 0.59–0.98）。
- 出處：Hughes 2013 *Ann Intern Med* [DOI](https://doi.org/10.7326/0003-4819-158-11-201306040-00002)
- 備註：防曬同時保護 A 醇/C 增敏後不被曬傷；是色素治療的天條。

### 保濕（屏障修復地基，也是「不適」第一線解方）
- 含**尿素+甘油**乳霜顯著降 TEWL（−9.0 g/m²/h vs 無處理）並保護皮膚不被 SLS 刺激（Danby 2022 *Clin Exp Dermatol* [DOI](https://doi.org/10.1111/ced.15141)）
- 保濕降 TEWL、病情分數 SCORAD 14→7（Goh 2020 *An Bras Dermatol* [DOI](https://doi.org/10.1016/j.abd.2019.11.007)）
- 純凡士林 paraffin 對屏障無效、反降天然保濕因子 NMF → **挑成分而非挑「保濕」二字**（Danby 2022 同上）
- 凡士林封閉降 TEWL 維持 >4h；矽靈不封閉（De Paepe 2014 *Skin Pharmacol Physiol* [DOI](https://doi.org/10.1159/000354914)）
- 椰子油 = 礦物油（Agero 2004 *Dermatitis* [DOI](https://doi.org/10.2310/6620.2004.04006)）

**有效保濕配方三層**：humectant（甘油/玻尿酸/尿素）+ occlusive（凡士林/角鯊烷）+ 屏障脂質（神經醯胺/菸鹼醯胺）。

## Part 2 — 療效層（早C晚A）

| | RCT 結果 | 出處 |
|---|---|---|
| **晚A**（A 醇/A 酸） | 12 週分臉 RCT：細紋、色斑、膚色、毛孔全面顯著改善；證據量最大 | McDaniel 2017 *J Cosmet Dermatol* [DOI](https://doi.org/10.1111/jocd.12381)；Babamiri 2010 *Aesthet Surg J* [DOI](https://doi.org/10.1177/1090820X09360704) |
| **早C**（外用 VC） | 5% VC vs 安慰劑 6 個月雙盲：微地形密度↑、深皺↓ | Humbert 2003 *Exp Dermatol* [DOI](https://doi.org/10.1034/j.1600-0625.2003.00008.x)；Humbert 2017 *JEADV* [DOI](https://doi.org/10.1111/jdv.14525) |

**注意**：A 是最可能的「不適」來源 → 需減量、緩衝。

## Part 3 — 色素層：傳明酸（tranexamic acid, TXA）

定位：處理痘痘平息後的**痘印（PIH）/ 暗沉 / 肝斑**。原理為抑制 plasmin → 減少黑色素活化。

| 給法 | 證據 | 出處 |
|---|---|---|
| 口服 | 250mg×2/日 ×3 月 → mMASI 降 **49% vs 安慰劑 18%** | Del Rosario 2017 *JAAD* [DOI](https://doi.org/10.1016/j.jaad.2017.09.053) |
| 口服最適劑量 | 250mg×3/日（750mg）×12 週（台灣團隊網絡統合） | Wang 2023 *IJDVL* [DOI](https://doi.org/10.25259/IJDVL_530_2021) |
| 三法比較 | 22 RCT/1280 人：口服 > 注射 > 外用 | Calacattawi 2024 *J Dermatolog Treat* [DOI](https://doi.org/10.1080/09546634.2024.2361106) |
| 定位 | 最強仍是外用 hydroquinone/三合一；口服 TXA 為有效輔助 | McKesey 2020 *Am J Clin Dermatol* [DOI](https://doi.org/10.1007/s40257-019-00488-w) |

**安全**：口服 TXA 為處方藥（影響凝血）→ **血栓/中風病史、含雌激素避孕藥者禁用/慎用**，須皮膚科評估。外用 2–3% 為台灣 TFDA 合法美白成分，OTC、低風險。

### 肝斑 vs 痘印（PIH）鑑別
- **肝斑（melasma）**：與肝無關，名源於醬色。對稱、片狀黃褐，好發兩頰/額/上唇；UV+荷爾蒙；頑固易復發 → 才更需口服 TXA。
- **PIH（你最可能）**：褐印正好長在舊痘位置；會隨時間（數月）自然淡化；防曬+C/A/niacinamide/外用 TXA 即可。
- **紅痘印（PIE）**：按壓會淡、偏紅；TXA、鎮靜、防曬。
- 自我判斷：印子對到舊痘位 → PIH；兩頰對稱大片、與痘無關 → 疑肝斑，建議皮膚科 Wood's lamp 確認。

## Part 4 — 飲食（全身性輔助）

- 低升糖負荷 RCT，43 名男性 12 週：痘痘 **−23.5 vs 對照 −12.0**（p=0.03），胰島素敏感性改善（Smith 2007 *Am J Clin Nutr* [DOI](https://doi.org/10.1093/ajcn/86.1.107)）
- 乳製品：僅觀察性關聯、無確定 RCT（Bhate 2013 *Br J Dermatol* [DOI](https://doi.org/10.1111/bjd.12149)）→ 可個人測試

## Part 5 — 台灣選品（依成分原則，非業配）

假設偏油/混合肌；乾肌乳霜再升一級。挑選時 ✅ glycerin / HA / ceramide / niacinamide / panthenol / squalane / petrolatum；❌ 高濃度酒精、香精、精油、過多酸。

### 化妝水（可有可無的補水第一層）
- 肌研 Hada Labo 極潤（玻尿酸）
- Curel 珂潤 潤浸保濕化妝水（pseudo-ceramide）

### 修護霜/乳霜（主力）
- **CeraVe 適樂膚**（神經醯胺+HA+MVE，無香精，CP 值高）← 首推
- 理膚寶水 La Roche-Posay：Cicaplast Baume B5（救火）、Toleriane（日常）
- Curel 珂潤 潤浸保濕乳霜
- 凡士林 Vaseline（純封閉劑，三明治最後一層）

### 美白/色素（含傳明酸）
- 開架/專櫃含 2–3% 傳明酸之美白精華（如資生堂 HAKU 系列等）
- 口服 TXA → 皮膚科處方，勿自行網購

---

## 疊加時序（屏障穩定後）

| 時段 | 步驟 |
|---|---|
| 早 | 潔面 → (化妝水) → 維生素 C → 保濕 → **防曬** |
| 晚 | (需卸才)卸妝 → 潔面 → 保濕霜 → A 醇/A 酸 → 保濕霜（三明治） |
| 不適期 | **暫停 A，只留保濕+防曬**，回穩再加回；傳明酸外用可擇一時段加入 |

---

## 行動清單
- [ ] 地基層先到位：每日防曬 + 對的保濕霜（CeraVe/Cicaplast）
- [ ] 晚A 降頻至每 2–3 晚一次 + 三明治緩衝，耐受後加頻
- [ ] 卸妝油只在有防曬/彩妝時用，純保養日溫和潔面
- [ ] 分辨痘印類型（對痘位=PIH，自然會淡；對稱大片=疑肝斑→皮膚科）
- [ ] 外用傳明酸可加入色素管理；口服 TXA 須皮膚科評估凝血風險
- [ ] 不適 >2–3 週或持續泛紅/丘疹/灼熱 → 排除酒糟/脂漏，就醫
