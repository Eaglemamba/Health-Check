# 2026 馬偕健檢 — 建議加測項目清單

**對應基準：** 2026-03-25 健檢（LDL 154 / TC 191 / HDL 39 / 尿酸 8.9 / HbA1c 5.9% / hsCRP 1.42 mg/L / AST 38 / BP 153/88 / FIB-4 = 0.96）
**前次基準：** 2025-09-17 健檢（LDL 177 / TC 234 / 尿酸 8.6 / HbA1c 6.0% / hsCRP 3.02 mg/L / 脂肪肝）
**用途：** 至馬偕健檢中心諮詢時，請對方核對以下項目是否已包含，未包含則加選
**建立日期：** 2026-04-20

## 一、核心加測清單（依優先順序）

| 優先 | 項目 | 為什麼要測 | 自費行情 | 頻率 |
|:---:|------|-----------|---------|------|
| 🔴 | **ApoB（載脂蛋白 B）** | LDL 154 + HDL 39 + HbA1c 5.9 + 既往脂肪肝 = 典型 ApoB/LDL-C discordance 高危族群；LDL-C 可能低估真實風險；是否需 statin 的關鍵佐證 | 300–500 TWD | 每次追蹤 |
| 🔴 | **Lp(a) 脂蛋白(a)** | AHA 2026 建議一生至少測一次；基因決定、無法靠飲食運動改變；若 > 125 nmol/L 心肌梗塞風險 2–3 倍，會直接改變積極治療門檻 | 600–1000 TWD | **一生一次** |
| 🔴 | **空腹胰島素（算 HOMA-IR）** | HbA1c 5.9（仍 prediabetes）+ 既往脂肪肝 → 胰島素阻抗高度可能；HOMA-IR > 1.9 對脂肪肝靈敏度 87%；比 HbA1c 早數年預警糖尿病進程 | 300–500 TWD | 每次追蹤 |
| 🔴 | **冠狀動脈鈣化分數 CAC** | 37 歲 + LDL 154 仍 borderline high + ECG 新增雙心房擴大/前壁 ST 上升 + CXR 主動脈扭曲 = 強烈建議族群；CAC = 0 可去風險化（延後 statin 討論）；反之若 > 0 應立即積極治療 | 3500–6000 TWD | 每 5 年 |
| 🟠 | **頸動脈超音波（IMT + plaque）** | 無輻射替代 CAC；視覺化是否已有斑塊；若預算有限可先選這個而非 CAC | 1500–2500 TWD | 每 2–3 年 |
| 🟡 | **GGT** | 脂肪肝 + 代謝症候群敏感指標；多數基礎套餐已含，確認即可 | 已含/100–200 TWD | 每次追蹤 |
| 🟡 | **sdLDL-C（小顆粒 LDL）** | 若不驗 ApoB 的替代方案；胰島素阻抗族群特別重要 | 500–800 TWD | 每次追蹤 |
| 🟢 | **FIB-4 指數** | 免費！AST + ALT + 血小板 + 年齡即可算，不需加錢；2026-03-25 算得 **0.96（低風險 < 1.30）** → **本次不需做 FibroScan** | 免費 | 每次健檢自行計算 |
| ⏸️ | ~~FibroScan 肝纖維化掃描~~ | **本次不建議加做**：FIB-4 = 0.96 已落在低風險區（< 1.30），NPV > 90%，臨床指引不需進一步影像；僅當未來 FIB-4 ≥ 1.30 才考慮 | — | 觸發時才做 |

## 二、馬偕健檢櫃台對話清單（直接列印用）

> 「您好，我想詢問貴套餐是否包含以下項目？若無，請協助加選並提供加價費用。」

### 心血管進階組
- [ ] **ApoB（載脂蛋白 B）**
- [ ] **Lp(a) 脂蛋白(a)** ← 一生一次必驗
- [ ] **冠狀動脈鈣化分數 CAC（Coronary Artery Calcium Score）**
- [ ] 頸動脈超音波（含 IMT 與斑塊評估）
- [ ] sdLDL-C（小顆粒 LDL，替代 ApoB 的選項）

### 代謝進階組
- [ ] **空腹胰島素（Fasting Insulin）** ← 用於計算 HOMA-IR
- [ ] C-peptide（可選）
- [ ] GGT（確認是否已含）

### 肝臟進階組
- [ ] AST / ALT / 血小板（確認已含，回家自算 FIB-4）
- [ ] GGT（確認是否已含）

### 以下可不加（CP 值低 / 本次不觸發）
- ✗ **FibroScan** — FIB-4 = 0.96 已屬低風險（< 1.30），臨床指引不需影像；未來 FIB-4 ≥ 1.30 再觸發
- ✗ 同半胱氨酸 Homocysteine — 證據弱，B 群補充 RCT 未降心血管事件
- ✗ 腫瘤標記全套（CEA / CA19-9 / AFP 等）— 敏感度特異度都低，不如影像 + 內視鏡
- ✗ hs-Troponin — 無症狀健檢非必要

## 三、配置方案比較

### 方案 A：馬偕套餐 + 加選（整合方便，推薦）
- 馬偕中階套餐（約 20,000–30,000 TWD）獲得影像（腹超、心電圖、胸部影像）+ 基礎血液
- 加選：ApoB + Lp(a) + 空腹胰島素 ≈ **+1,500–2,500 TWD**
- 首次加 CAC ≈ **+5,000 TWD**
- **總預算：約 27,000–37,000 TWD**（FibroScan 因 FIB-4 低風險暫不加）

### 方案 B：馬偕做影像 + 獨立檢驗所驗血（省錢）
- 馬偕只做影像（肺部低劑量 CT、腹超、心電圖、CAC）
- 血液項目到獨立檢驗所自由配（元順等）→ 便宜 30–50%
- 缺點：報告分散、整合麻煩

### 方案 C：分階段（最省）
1. **先自費驗便宜的**：ApoB + Lp(a) + 空腹胰島素 ≈ 1,500 TWD
2. **依結果再決定影像**：
   - ApoB 偏高 或 Lp(a) > 125 nmol/L → 加做 CAC
   - 未來 FIB-4 ≥ 1.30（目前 0.96 暫時無須） → 再加做 FibroScan

## 四、判讀門檻快速參考

### ApoB 目標（NLA 2024 共識）
| 風險分層 | ApoB 目標 |
|---------|----------|
| 中度風險 | < 90 mg/dL |
| 高風險 | < 70 mg/dL |
| 極高風險 | < 60 mg/dL |

### Lp(a) 風險分層
- < 75 nmol/L（< 30 mg/dL）：低風險
- 75–125 nmol/L：中等
- **> 125 nmol/L（> 50 mg/dL）：高風險，心肌梗塞 2–3 倍**

### HOMA-IR 判讀（公式：空腹胰島素 × 空腹血糖 ÷ 405）
- < 2.0：正常
- 2.0–2.9：早期胰島素阻抗
- **≥ 3.0：需要介入**
- > 1.9 對脂肪肝的靈敏度 87%

### CAC 分數
- **0：強力去風險化**（即使 LDL 154 也可延後 statin）
- 1–100：輕度
- 100–400：中度
- > 400：高度（積極治療）

### FIB-4（年齡 < 65）
- **< 1.30：低風險**（你目前 0.96 ✅）
- 1.30–2.67：不確定區，需 FibroScan
- > 2.67：高風險

### FibroScan 硬度（kPa）— 觸發時才做的參考
- < 7.0：F0–F1（無/輕度纖維化）
- 7.0–9.5：F2（中度）
- 9.5–12.5：F3（進階）
- > 12.5：F4（肝硬化）
- **觸發條件：FIB-4 ≥ 1.30 才需進一步做 FibroScan**

## 五、抽血前注意事項

- **空腹 ≥ 10 小時**（胰島素、血脂、FIB-4 精準性）
- **抽血前 48 小時避免劇烈運動**（AST 會因肌肉損傷上升，影響 FIB-4）
- **抽血前 24 小時避免酒精**（AST/ALT 比值會偏高）
- **Lp(a)：任何時間皆可**（基因決定、不受飲食影響），但配合其他項目一起空腹最省事
- ~~FibroScan：空腹 3 小時以上~~（本次不做，FIB-4 低風險）
