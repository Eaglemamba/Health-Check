# Retinol + UVA Pro 起步 protocol — 2026-05-28

*個人化臉部抗老化 protocol。配對閱讀：[skincare RCT evidence](2026-05-26-skincare-rct-evidence.md)*

## 採用產品

| 品項 | 規格 | 角色 |
|------|------|------|
| **CeraVe Resurfacing Retinol Serum** | 0.1% 包覆型 retinol + ceramide 1/3/6-II + niacinamide | PM 主動修復（細紋、痘印、膠原刺激） |
| **La Roche-Posay Anthelios UVMune 400 (UVA Pro)** | Mexoryl 400 廣譜 + 廣譜 UVB；SPF 50+ / PPD 高階 | AM 必備防曬（含 380–400 nm 長 UVA1） |

## 為什麼這對組合（一句話）

Retinoid 是抗光老化臨床證據最強的分子（Kligman 1986 起，Mukherjee 2006 綜述）；但 retinol 提高光敏感性，且 UVA1（380–400 nm）是真皮 collagen MMP-1 降解的主力波長，一般 SPF 擋不到——**Mexoryl 400 補上這段缺口**。兩者不可拆開使用。

## 起步排程（前 12 週）

| 週次 | PM Retinol 頻率 | AM UVA Pro | 觀察重點 |
|------|----------------|------------|---------|
| 1–2  | 每週 2–3 晚 | 每日 | 視黃醇化（retinization）：泛紅、脫屑、緊繃 |
| 3–4  | 隔日 1 晚 | 每日 | 適應度；若無強刺激即進階 |
| 5–8  | 隔日 → 每晚 | 每日 | 痘印開始淡化（PIH 8–12 週 RCT 約 30–40% 改善） |
| 9–12 | 每晚 | 每日 | 質地改善開始可見；細紋 12–16 週起 |

豆大量（pea-size）塗全臉。**乾臉再上**：洗完臉等 15–20 分鐘到完全乾，降低刺激。

## 配搭規則

**可同時使用**
- AM：維 C → 保濕霜 → **UVA Pro**（早一定要防曬）
- PM：洗臉 → 等乾 → **retinol** → 保濕霜（敏感期用「三明治」：保濕 → retinol → 保濕）
- 菸鹼醯胺、玻尿酸、ceramide、胜肽：任何時段皆可配

**不可同晚疊**
- BHA / AHA（水楊酸、果酸、杏仁酸）
- Benzoyl peroxide（氧化 retinol）
- 高濃度 vitamin C（pH 衝突；分時段 AM/PM 即可）
- 物理性磨砂、清潔粒子

**完全停用窗口**
- 雷射 / 煥膚 / 微針 / 注射前 **≥ 1 週**
- 急性曬傷或皮膚屏障破損期間
- 任何發炎性皮膚病灶活動期

## 適應期不良反應 SOP

| 症狀 | 行動 |
|------|------|
| 輕度泛紅、脫屑、緊繃 | 正常，加強保濕；不減頻 |
| 「爆痘排毒」（純粹小痘） | 正常代謝加速，4–6 週內消退 |
| 中度刺痛 / 脫皮明顯 | 降頻至每週 1–2 晚 + 三明治法 |
| 強灼熱 / 水疱 / 滲液 | **立即停用 ≥ 2 週**，純保濕修復後 1 晚再試半量 |
| 感染（紅腫熱痛、化膿） | 停用，皮膚科評估 |

## 與每日 routine 銜接

- **AM 09:30 錨點（出門前）**：洗臉 → 保濕 → **UVA Pro**（1 元硬幣量，全臉 + 頸 + 耳後）。重塗：戶外 > 2 小時或大量流汗。
- **PM 20:30 wind-down 前**：洗臉 → 等乾 → **retinol PM**（豆大量）→ 保濕霜
- 之後可正常進行睡前 routine（鎂、酸櫻桃、glycine）
- 睡眠改善與 retinol 雙線並行 = 皮膚修復最強組合（睡眠期是膠原合成峰值；retinol 提供誘導訊號）

## 追蹤指標（每月一次）

| 指標 | 方法 | 目標 |
|------|------|------|
| 痘印（PIH/PIE） | 同光線同角度自拍兩頰 + 臀部 | 8–12 週 30%+ 淡化 |
| 新活動性痘痘 | 每週數量 + 部位 | 維持 ≤ 1 顆/週 |
| 細紋 | 額頭、眼周、法令紋自拍 | 12–16 週可見質地改善 |
| 刺激度 | 1–5 分主觀；脫皮/泛紅 0/1/2 | 持續減少 |
| 防曬執行率 | 每日 daily 計畫表勾選 | ≥ 95% |

## 預期時間軸（RCT 基準）

- **防曬保護**：立即生效（每日抹）
- **PIH（痘印）淡化**：8–12 週可見，12 週後 30–40% 改善（retinol 0.1% RCT 範圍）
- **質地細緻化、毛孔**：8–12 週
- **細紋**：12–16 週首見改善
- **膠原 remodeling**：持續 6–12 個月才達穩態
- **真疤（凹陷、結構性）**：retinol 無效；後續評估 fractional laser / subcision / 微針

## 對個人脈絡的整合

- **2026-05-26 daily 觀察**：OSA 介入後活動性痘痘消退（睡眠 → 皮質醇 ↓ → 發炎 ↓）。**現在加 retinol = 預防 + 修復雙線**：預防新痘（角質代謝）+ 淡化已留痘印 + 抗光老化打基底。
- **47 歲起步不晚**：retinol 越早累積膠原 ROI 越高，但 40+ 起步仍可在 6 個月見明顯緊緻度改善。
- **OSA soft marker 連動**：若皮膚再次惡化（新痘 ↑、暗沉），檢查睡眠（Sleep Score、SpO2）是否同步劣化——皮膚是慢性發炎的對外鏡子。

## 停用 / 暫停觸發

- 雷射 / 煥膚 / 微針 / 注射計畫前 **≥ 1 週**停用
- 計畫做侵入性醫美處置：停用至傷口完全修復
- 嚴重曬傷、皮膚屏障明顯受損：停用至完全恢復
- 任何過敏反應（廣泛紅疹、腫脹、灼熱）：立即停用 + 皮膚科

## 文獻基礎（綜覽）

- **Retinoid 抗光老化**：Kligman AM（1986 起，tretinoin 系列）；Mukherjee S et al., *Clinical Interventions in Aging* 2006（綜述）
- **0.1% retinol 效力**：多篇 RCT 顯示 0.05–0.5% retinol 12–16 週改善細紋、彈性、色素（綜述見 *J Cosmet Dermatol* 系列）
- **PIH 改善**：Bulengo-Ransby SM et al., *NEJM* 1993（tretinoin 對 PIH）；Halder RM et al., 1998（深膚色 PIH）
- **UVA1 與光老化**：Krutmann J et al.（UVA1 → MMP-1 → 真皮 collagen 降解機制系列）
- **Mexoryl 400**：Seité S, Fourtanier A 等 La Roche-Posay 團隊驗證（廣譜 UVA1 至 400 nm）

引文僅列代表性方向；個別決策請回查原始 RCT 與 meta-analysis（PubMed）。
