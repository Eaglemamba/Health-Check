# 單糖與雙糖 — 代謝機制與食物來源

**建立日期：** 2026-04-16
**適用情境：** 減脂期飲食選擇參考

---

## 單糖（Monosaccharides）

### 1. 葡萄糖 Glucose

**代謝路徑**

- 小腸吸收 → 血糖上升 → 胰島素分泌 → GLUT4 載體將葡萄糖送入肌肉/脂肪細胞
- **糖解作用（Glycolysis）**：葡萄糖 → 丙酮酸 → 進入粒線體 TCA cycle → 產生 ATP
- 多餘的 → **肝醣合成（Glycogenesis）**：儲存於肝臟（~100g）和肌肉（~400g）
- 肝醣滿載後 → **脂肪新生（De novo lipogenesis）**：轉為三酸甘油酯存入脂肪組織
- 全身細胞都能用，是大腦的主要燃料

**存在食物**

- 米飯、麵條、麵包（澱粉分解後的最終產物）
- 葡萄、香蕉、蜂蜜
- 運動飲料、葡萄糖錠

---

### 2. 果糖 Fructose

**代謝路徑**

- 小腸吸收 → **幾乎 100% 由肝臟代謝**（不走胰島素路線）
- 果糖 → 果糖-1-磷酸 → 甘油醛 + 磷酸二羥丙酮
- 關鍵差異：**繞過糖解作用的限速酶（PFK-1）**，不受能量狀態調控 → 無限制地進入脂肪合成
- 大量攝取時：
  - → **VLDL 合成 ↑** → 血中三酸甘油酯 ↑
  - → **肝臟脂肪堆積** → 非酒精性脂肪肝（NAFLD）
  - → **尿酸 ↑**（果糖磷酸化消耗 ATP → AMP → 尿酸）
  - → **瘦素阻抗** → 飽足感下降 → 過食
- **不刺激胰島素、不抑制飢餓素（ghrelin）** → 吃了不覺得飽

**存在食物**

- 水果（蘋果、梨、芒果、荔枝 — 但水果含纖維，減緩吸收）
- 蜂蜜（~40% 果糖）
- **高果糖玉米糖漿（HFCS）**：手搖飲、汽水、糖果、加工食品 ← **最大殺手**
- 龍舌蘭糖漿（~85% 果糖）

---

### 3. 半乳糖 Galactose

**代謝路徑**

- 小腸吸收 → 肝臟中經 **Leloir pathway** 轉化為葡萄糖-1-磷酸 → 進入葡萄糖代謝
- 半乳糖 →（半乳糖激酶）→ 半乳糖-1-磷酸 →（轉移酶）→ UDP-葡萄糖 → 葡萄糖代謝
- 缺乏轉移酶 → **半乳糖血症**（新生兒篩檢項目）

**存在食物**

- 很少單獨存在，主要來自乳糖分解
- 牛奶、優格、起司
- 少量存在於甜菜、某些豆類

---

## 雙糖（Disaccharides）

### 4. 蔗糖 Sucrose ＝ 葡萄糖 + 果糖

**代謝路徑**

- 小腸刷狀緣的 **蔗糖酶（sucrase）** 水解為 1 葡萄糖 + 1 果糖
- 各自走上述路徑 → **50% 的糖走肝臟果糖路線**
- 這就是為什麼「含糖飲料」對內臟脂肪傷害大 — 每口都有一半是果糖

**存在食物**

- 白糖、紅糖、冰糖、黑糖（都是蔗糖）
- 手搖飲的「糖」、烘焙甜點
- 甘蔗、甜菜
- 水果中天然存在（但比例較低）

---

### 5. 乳糖 Lactose ＝ 葡萄糖 + 半乳糖

**代謝路徑**

- 小腸刷狀緣的 **乳糖酶（lactase）** 水解為葡萄糖 + 半乳糖
- 各自吸收代謝
- **乳糖不耐**：成人乳糖酶減少 → 未分解的乳糖進入大腸 → 腸道菌發酵 → 脹氣、腹瀉
- 東亞人群 ~80–90% 有不同程度乳糖不耐

**存在食物**

- 牛奶（~4.8g/100ml）、羊奶
- 優格（發酵後乳糖降低 20–30%）
- 鮮奶茶（無糖鮮奶茶的主要糖分來源）
- 冰淇淋、奶油
- 起司（硬質起司乳糖極低）

---

### 6. 麥芽糖 Maltose ＝ 葡萄糖 + 葡萄糖

**代謝路徑**

- **麥芽糖酶（maltase）** 水解為 2 個葡萄糖
- 100% 走葡萄糖路線 → 血糖反應快且高（GI 值 ~105，比葡萄糖還高）
- 雙倍葡萄糖 → 胰島素反應強烈

**存在食物**

- 麥芽糖漿（台灣傳統糖蔥、麥芽餅）
- 啤酒（麥芽發酵中間產物）
- 米漿、甘酒
- 澱粉消化的中間產物（吃飯咀嚼久了的甜味）

---

### 7. 海藻糖 Trehalose ＝ 葡萄糖 + 葡萄糖（α,α-1,1 鍵結）

**代謝路徑**

- **海藻糖酶（trehalase）** 水解為 2 個葡萄糖
- 但水解速度比麥芽糖慢 → **血糖上升較緩**（GI ~70）
- 少數人缺乏海藻糖酶 → 類似乳糖不耐的腹瀉

**存在食物**

- 菇類（香菇、杏鮑菇）
- 蝦、酵母、海藻
- 日本和菓子、甜點常用作代糖
- 某些能量飲料

## 減脂期實用摘要

| 糖類 | 內臟脂肪風險 | 血糖衝擊 | 主要來源 |
|---|---|---|---|
| **果糖** | ★★★★★ | 低（但傷肝） | 手搖飲、水果過量 |
| **蔗糖** | ★★★★ | 中高 | 含糖飲料、甜食 |
| **麥芽糖** | ★★★ | 極高 | 米漿、傳統甜食 |
| **葡萄糖** | ★★ | 高 | 白飯、麵食 |
| **乳糖** | ★ | 中低 | 鮮奶、鮮奶茶 |
| **半乳糖** | ★ | 低 | 乳製品 |
| **海藻糖** | ★ | 中低 | 菇類、少量 |

### 減脂期三大應避免

1. **果糖**（液態果糖 / HFCS） — 直接進肝臟合成脂肪，不產生飽足感
2. **蔗糖** — 一半是果糖，含糖飲料是雙重打擊
3. **麥芽糖** — GI 極高，血糖胰島素劇烈波動

> 水果裡的果糖因為有纖維包覆，吸收慢很多，一天 1–2 份不用怕。真正的敵人是**液態糖**（飲料、糖漿），沒有纖維減速，直接灌進肝臟。
