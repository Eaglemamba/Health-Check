# 肌力追蹤與握力訓練 — 把「肌力 > 肌肉量」落地（含握力 30kg 發現）

**建立日期：** 2026-06-12（W24 D5）
**讀者錨點：** David（37 歲男性，170 cm，66.5 kg；FFMI 18.5、握力初測 ~30 kg；HTN、LVH + 雙心房擴大、OSA；2021 後重啟重訓）
**用途：** 把「肌力是比肌肉量更好的健康指標」從觀念變成**可量測、可訓練、可追蹤**的執行方案——尤其在握力初測偏低後。
**相關：** [增肌目標與 FFMI 軌跡](2026-06-12-muscle-gain-targets-ffmi-trajectory-and-training-style.md)（為何肌力 > 肌肉量）、[1x/2x 課表](2026-06-11-recomp-resistance-program-1x-2x.md)、[2 練執行 SOP](2026-06-12-training-execution-recovery-gate-and-post-workout-sop.md)
**非醫療建議；個人化於上述背景（特別是心臟與 OSA）。**

---

## 0. 為什麼用握力/肌力當記分板（而非 FFMI）

- **證據**：握力與全因死亡率近乎**線性**負相關（~200 萬人 meta，最強組死亡率 ↓31%，Garcia-Hermoso 2018）；肌肉「量」則是 U 型。**低握力比低肌肉量更能預測死亡**。
- **FFMI 不可靠**：FFM ≠ 純肌肉（含水/肝醣），且家用 BIA 受水合影響大、會被一頓大餐騙（見 FFMI 軌跡篇 §四的 2026-03 虛高案例）。
- **結論**：追蹤標靶從「FFMI 數字」升級為「**肌力（握力 + 估算 1RM）**」——更強的健康預測子，且安全可測。

---

## 1. 握力初測發現：~30 kg（偏低，但高度可逆）

| 參考（男性）| 數值 |
|------------|------|
| 肌少症切點 | **< 28 kg**（AWGS 2019）/ < 27（EWGSOP2）|
| **個人初測** | **~30 kg**（剛好在切點上方）|
| 30–39 歲期望值 | ~45–49 kg |
| 階段目標 | **40+ kg**（脫離警戒、進入健康帶）|

**判讀**：30 kg 對 37 歲偏低，落在肌少症切點上緣，比同齡期望低 ~15 kg。這**印證了**終身低 FFMI（~18）+ skinny-fat/TOFI + 「HDL 下降是肌肉缺席指紋」——**握力是這一切的功能性鐵證**。但起點低 = **進步最快**，肌力神經適應數週見效，**數月～一年 30 → 40+ kg 可達**。把它當「真實、可量化、高度可逆的健康缺口」來補，而非焦慮。

---

## 2. 先標準化「重測」（單次廉價握力計常低估）

下任何結論前先排除測量誤差：

| 常見低估原因 | 修正 |
|------------|------|
| **握距沒調好** ← 最常見 | 握把寬度調到**適合手掌**（太寬太窄都大幅低估）|
| 姿勢借力 | 站姿、手臂自然下垂或手肘 90°（依器材），不夾身體 |
| 沒全力/次數不足 | **全力握 3–5 秒**，每手 3 次**取最高**，用慣用手最佳值 |
| 器材未校準 | 換一台或用健身房機械式 dynamometer 對照 |

**先以標準流程重測確認真實基準**，再開始追蹤。

---

## 3. 怎麼練握力（高 ROI → 低；觀念：握力大半是「全身強壯」的 proxy）

| 方法 | 做法 | 為什麼 |
|------|------|--------|
| **① 拉的動作不用拉力帶** | RDL/划船/下拉先徒手握，握不住才在最後重組用帶 | 免費、已在練；別用帶把握力 bypass |
| **② 農夫走路 loaded carry** | 雙手提重啞鈴/壺鈴走 20–40m × 2–3 組 | 最佳專項 + 全身；安全無憋氣、對心臟零風險 |
| **③ 死掛 dead hang** | 吊單槓撐到極限 × 3–5 組 | 握耐力 + 肩健康 + 脊椎減壓 |
| **④ 握力器 gripper** | **可調阻力**款，每側 3 組近力竭 | 練 dynamometer 的 crush grip；辦公室/通勤可做 |

---

## 4. Bonus：等長握力訓練（IHG）順便降血壓

對你（HTN）一魚兩吃——**等長握力訓練是降 BP 證據最強的非藥物介入之一**，與你已做的**靠牆深蹲同家族**（Edwards 2023 BJSM 等長運動 meta）。

**protocol**：握力計/彈簧器，**30% 最大力持續握 2 分鐘 × 4 回（休 1 分），每週 3 次** → 降靜息 SBP 數 mmHg。同時練握力 + 降血壓。

---

## 5. 安全（對你）

- **握力訓練對心臟低風險**（非大重量軸向負荷）——與 1RM 完全不同，可放心做。
- 但**訓練用次大強度、保持呼吸**，別「憋氣硬擰到極限」（IHG 用 30%，非 max）。
- 最大值「測量」一下追蹤可以，但**訓練不拚 max**（呼應：不測/不練 1RM 的心臟禁忌）。

---

## 6. 肌力追蹤欄（季度填寫；取代 FFMI 當主記分板）

> 估算 1RM（e1RM）：從 8–12 下工作組回推，**不用真的拚 max**。公式 e1RM ≈ 重量 ×(1 + 次數/30)。

| 季度 | 握力（慣用手，kg）| 深蹲 e1RM | RDL/硬舉 e1RM | 臥推/胸推 e1RM | 划船 e1RM | 備註 |
|------|------------------|-----------|---------------|----------------|-----------|------|
| 2026-Q2（基準）| ~30（待標準化重測）| | | | | 初測；握距待校正 |
| 2026-Q3 | | | | | | |
| 2026-Q4 | | | | | | |
| 2027-Q1 | | | | | | |

**判讀規則**：
- 握力**目標 40+ kg**（脫離 28 警戒）；每季應緩步上升。
- e1RM 緩步上升 = recomp 肌肉/肌力進步的真訊號（比體重計/FFMI 可靠）。
- 若握力連 2 季停滯或下降 → 檢視睡眠/OSA（恢復瓶頸）與蛋白攝取。

---

## 7. 一週整合（不費時）

- **健身房日**：拉動作徒手握 + 課後農夫走路 2–3 組 + 死掛 2–3 組（+~5 分）。
- **非健身日/辦公室**：握力器或 IHG 3 次/週（IHG ~12 分，順便降 BP）。
- **每季**：握力計標準化測一次，填入 §6 追蹤表。

---

## 結論

握力初測 ~30 kg 偏低，是你目前**最有用的一個數字**——比會被大餐/BIA 騙的 FFMI 真實太多。它給你明確起點（30）、健康目標（40+）、與進步最快的路。**先把握距調好重測確認基準**，然後用「全身肌力 + 農夫走路/死掛/握力器 + IHG」去練，**季度用握力計 + e1RM 追蹤**。這就是把「肌力 > 肌肉量」從觀念變成你每季看得到進步的健康記分板。
