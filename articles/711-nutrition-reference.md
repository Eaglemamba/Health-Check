# 7-11 快查營養成分對照表

**用途**：日常飲食紀錄快速查值，對齊 `index.html` 每日營養目標（減重期 1,800 kcal / 蛋白質 95 g / 脂肪 50–65 g / 碳水 225–250 g / 纖維 ≥25 g / 鈉 <1,500 mg）。
**數值來源**：以 `index.html` 已驗證數值為主；未列於 index.html 者採標籤常見範圍，**實際購買仍以包裝營養標示為準**。
**評分邏輯**：
- 🟢 推薦：蛋白質密度 ≥15% 或屬 DASH 明星食材（低鈉 / 高鉀 / 高纖）
- 🔵 可用：蛋白質密度 10–15% 或需搭配使用
- 🟡 注意：單項偏鈉或偏脂，需控制份量
- 🔴 避免：鈉 >900 mg 或熱量 >550 kcal 或屬高普林/反式脂肪前體

## 八、最佳 Combo（直接抄）

### 早餐 Combo（~380 kcal / 36 g P）
```
雪坊 6 號優格 150 g + ON 乳清 1 匙 + 杏仁奶 100 cc
+ 香蕉 1 根 + 奇亞籽 10 g
= 381 kcal / 36 P / 10.5 F / 38 C / 7.8 fiber
```

### 午餐 Combo A（~613 kcal / 40 g P / ~900 mg Na）— 經典首選
```
香烤雞胸鮮蔬餐 (374 kcal)
+ 光泉無加糖黑豆漿 400 ml (142 kcal)
+ 鹽味毛豆 1 包 (97 kcal)
= 613 kcal / 40.3 P / 12 F / 65 C / 8+ fiber / ~892 Na
```

### 午餐 Combo B（~400 kcal / 30 g P / ~450 mg Na）— 超低鈉
```
蒸番薯 1 條 + 即食雞胸肉 1 包 + 黑豆漿 400 ml
= 376 kcal / 38 P / 8 F / 48 C / 4 fiber / ~480 Na
```

### 午餐 Combo C（~530 kcal / 35 g P）— 高 leucine 跨門檻
```
茶葉蛋 ×3 + 蒸番薯 + Simple Fit 沙拉（半醬）+ 健康穀物豆漿
= 530 kcal / ~35 P / ~13 F / ~60 C / ~7 fiber / ~700 Na
```

### 晚餐 Combo（若家中不開伙）
```
雞胸肉花椰菜飯減醣餐 (319 kcal)
+ 涼拌木耳 (60 kcal)
+ 鮮乳低脂 290 ml (130 kcal)
= 509 kcal / ~35 P / ~14 F / ~45 C / ~8 fiber
```

## 十、使用備註

1. **鈉是 ISH 最敏感的變數**：單餐鈉 <800 mg，單日 <1,500 mg 是硬目標
2. **蛋白質密度是決定要不要算的關鍵**：<10% 的食物當「佐菜」看，不要計為蛋白質來源
3. **雞肉沙拉類整體蛋白質密度通常不高**（凱薩本體 9.2% 僅 9.6 g/份），需要額外補蛋白單品
4. **7-11 便當熱量普遍在 320–450 kcal 間**，單餐配 1 份豆漿或雞胸即可補足
5. **數值均為估算範圍**，實際購買請以包裝營養標示為準，特別是 **鈉** 常因製程批次差異
