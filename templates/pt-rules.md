# 物理治療 & 健康管理建議規則

每日 check-in 完成記錄後，根據以下規則**自動提供簡短建議**（2-3 句，不打斷 3 分鐘節奏）。建議以「💡 PT 建議：」開頭，附在紀錄尾端。

## 一、身體信號觸發建議

依據回報的**部位 + 性質**，提供對應的物理治療自我照護建議：

| 部位 | 常見性質 | 建議方向 |
|------|----------|----------|
| 前臂 / 手腕 | 酸緊、僵硬 | 前臂伸展（手掌朝上，另一手輕壓手指向下 30 秒 ×2）；工作每 50 分鐘休息活動手腕 |
| 肩胛骨 | 酸緊、沉重 | 肩胛骨收放（Y-T-W 靠牆動作 8 下 ×2 組）；檢查螢幕高度是否低於視線 |
| 頸部 | 僵硬、緊繃 | 頸部側彎伸展 30 秒/側；收下巴運動 10 下（改善前頭姿勢） |
| 下背 | 痠痛、僵硬 | 貓牛式 8 下 ×2；避免久坐超過 45 分鐘；坐姿時用腰靠 |
| 膝蓋 | 痠痛 | 確認靠牆深蹲角度是否太深，退回上一階段；髕骨活動術（坐姿推髕骨上下左右） |
| 肩膀 | 痠痛、活動度受限 | 肩關節鐘擺運動；胸椎旋轉活動度練習；暫停伏地挺身相關動作 |
| 髖部 | 緊繃 | 90/90 髖關節活動度練習；半跪姿髂腰肌伸展 30 秒/側 |
| 足底 | 疼痛 | 凍水瓶踩滾 2 分鐘；小腿拉伸（弓箭步靠牆）30 秒 ×2/側 |

**通用規則：**
- 同一部位**強度 ≥ 5** → 建議當天該部位避免高負荷訓練，改做輕度活動
- 同一部位**強度 ≥ 7** → 建議暫停相關運動，48 小時觀察，未改善就預約物理治療
- 同一部位**連續 3 天非清** → 提供該部位的完整居家復健菜單（3-4 個動作）
- 同一部位**連續 5 天非清或強度持續 ≥ 5** → 強烈建議預約物理治療師評估

## 二、數據異常觸發建議

比對前日或本週趨勢，若出現以下異常自動提示：

**體重：**
- 單日波動 > 1 kg → 提醒可能是水分/鈉攝取變化，非脂肪變化，不必緊張
- 一週增加 > 0.5 kg → 檢視本週飲食和飲水執行率，是否有外食增加
- 一週減少 > 1.5 kg → 警告太快，有痛風發作和膽結石風險，建議放慢

**血壓：**
- 睡眠不佳時（Sleep Score < 65 或實際睡眠時數 < 5 小時或主觀恢復感 ≤ 2），收縮壓通常會比正常值高約 5 mmHg，屬於預期波動，提醒補眠即可，不必額外緊張
- 收縮壓比前日上升 > 15 mmHg → 確認是否昨晚睡眠不足、壓力大、或攝入高鈉食物
- 收縮壓連續 3 天 > 140 → 建議回診諮詢醫師
- 收縮壓 < 100 → 確認是否頭暈，注意起身速度，增加飲水
- 心率突然上升 > 15 bpm（相比本週均值）→ 確認是否生病、脫水、或壓力過大

**睡眠：**
- Sleep Score < 65 → 提醒當天運動強度降一級（RPE 不超過 4/10），優先恢復
- Sleep Score < 65 + Body Battery < 40 → 建議當天只做輕度伸展，暫停靠牆深蹲和快走
- Body Battery 連續 3 天 < 50 → 提醒：你的恢復力嚴重不足，檢視睡眠修復方案中的三個要點（飲水截止 17:00、睡前抬腳、5:30 前不離床）
- 總睡眠時長 < 6h 連續 2 天 → 警示對 BP 153/88 與 HbA1c 5.9 控制不利，優先補眠
- 深眠 < 45 min 連續 2 天 → 夜間降壓效果打折，檢視睡前藍光 / 咖啡因截止時間
- REM < 60 min → 認知 / 情緒恢復不足，當天減少高認知負荷決策
- 主觀恢復感 ≤ 2 → 今天以恢復為主，建議做 10 分鐘溫和伸展取代原定運動計畫
- 主觀恢復感與 Garmin 數據嚴重不符（例如 Score 80 但主觀 2）→ 提醒留意是否有心理壓力、情緒因素

**SpO2（OSA 篩檢紅旗）：**
- 當晚最低 SpO2 < 88% → OSA（阻塞性睡眠呼吸中止）風險紅旗
- 連續 3 晚最低 SpO2 < 88% → **強烈建議**預約多項睡眠生理檢查（PSG），同步觀察晨起口乾、白天嗜睡、打鼾
- 日均 SpO2 < 93% → 排除急性呼吸道症狀；若無症狀，仍需注意
- 結合 BP 153/88 + BMI 24.5 + 前期糖尿病 → OSA 高風險三角，任何 SpO2 異常都不宜忽略

**SpO2 epoch-level desat events（自 2026-05-01 起追蹤；資料源 `scripts/analyze_spo2_desats.py`）：**
- T90 ≥ 10% → 🔴 hypoxic burden 重度單晚
- 任何單一 event 持續 ≥ 15 分鐘 → 重度累積缺氧訊號（比瞬間最低值更臨床有意義）
- 任何單一 event 最低 < 80% → 重度單點 desat
- 連續 3 晚 T90 > 10% 或 event > 15 分 → PSG 預約進度追蹤升為當週首要任務
- 入睡後 < 60 分鐘即出現 ≥ 5 分鐘 < 90% event → 典型 OSA 早期 N1/N2 阻塞 pattern

**Garmin RHR：**
- RHR > 67 bpm 連續 3 天 → 發炎 / 恢復不足 / 感染前兆警示
- RHR 在 3 天內上升 ≥ 5 bpm（相比基準 60-62）→ 可能將生病 / 過度訓練 / 壓力累積
- RHR < 50 且主觀恢復感 ≤ 3 → 可能迷走神經張力過高 / 電解質異常，留意

**Garmin 日均壓力：**
- > 40 連續 2 天 → 自律神經失調警示，對 BP 控制不利，建議加入 4-7-8 呼吸練習
- > 50 當天 → 當天訓練降級為輕度活動，優先放鬆
- < 25 且 Body Battery > 70 → 恢復狀態優，可按計畫進階

**步數（UA / HbA1c 控制關鍵）：**
- 當天 < 5,000 → 提醒：UA 排泄與葡萄糖代謝需要活動，明天補回
- 連續 3 天 < 5,000 → UA 與 HbA1c 控制風險升高，本週至少安排 2 次快走
- 連續 2 天 ≥ 10,000 且 RHR 未升高 → 正向回饋，維持
- **體重停滯偵測（baseline ~13,000 步）**：當週平均步數比前 2 週均值 −3,000 以上 → 即使飲食不變，每日少燒 200–250 kcal，5 天累計 ≈ 0.15 kg 脂肪沒掉 + 滯水 0.5–1 kg，會在體重計上呈現「卡關」假象；不是平台期，是輸入端短少

**雨天 / 步數補位 SOP（避免天氣依賴）：**
1. **室內取代**：辦公室或家中走路，午休 15 min × 2 = 1,500–2,000 步
2. **通勤調整**：早一站下車或繞遠路，單趟 +1,500–2,000 步
3. **強制觸發**：步數 < 9,000 連 2 天 → 第 3 天強制補 30 min 室內走路或固定式單車
4. **優先順序**：BB 起床連續 < 50 時，補步數優於加訓練強度（cortisol 已偏高，再加阻力訓練只會放大滯水）
5. **目標下限**：即使雨天，每日 ≥ 8,000 步為硬底線；低於此線當日補室內運動 20 min

**飲水（高尿酸優先指標）：**
- 目標：每日 ≥ 2.5L；高尿酸族群最佳區間 2.8–3.0L
- 當日實際 < 2.0L → 警示 UA 排泄效率降低，明日起床先喝 500 mL 補回
- 連續 2 天 < 2.0L → UA 8.9 + BP 153/88 雙重風險，本週重點關注
- 當日實際 < 1.5L → 強烈警示，加上高鈉食物會讓 BP 當晚偏高
- 17:00 前應完成 60-70%（避免夜尿干擾深眠）
- 連續 3 天達 ≥ 2.5L → 正向回饋

## 三、運動安全與調整建議

根據當天身體狀態，自動調整運動建議：

- **恢復充足**（Sleep Score ≥ 70 + 身體信號「清」+ 主觀 ≥ 4）→ 可按計畫執行或嘗試進階
- **恢復一般**（Sleep Score 65-70 或身體信號 1-2 處輕微）→ 按計畫執行，不進階
- **恢復不足**（Sleep Score < 65 或 Body Battery < 40 或主觀 ≤ 2）→ 降級：靠牆深蹲減一組或減 10 秒/組；快走改散步
- **有疼痛信號**（任何部位強度 ≥ 5）→ 避免涉及該部位的動作，提供替代方案

**靠牆深蹲特別注意：**
- 膝蓋有任何不適 → 退回上一階段角度，確認姿勢六要點
- 做完後膝蓋痛持續 > 2 小時 → 暫停 3 天，重新從更淺角度開始
- 做的時候頭暈或胸悶 → 立即停止，可能是憋氣或血壓問題

## 四、模式識別（週回顧時使用）

週回顧時自動分析以下模式，並在「本週觀察」提供摘要：

- **上交叉症候群模式：** 前臂 + 手腕 + 肩胛骨 + 頸部反覆出現 → 建議每日胸椎活動度 + 肩胛穩定訓練，檢視工作站人體工學
- **下肢負荷模式：** 膝蓋 + 髖部 + 足底反覆出現 → 檢視靠牆深蹲進度是否太激進，是否需要加入暖身
- **恢復不足模式：** Sleep Score 週均 < 65 + 身體信號頻繁 → 優先處理睡眠，本週運動降級
- **壓力累積模式：** 血壓上升趨勢 + 心率上升 + Sleep Score 下降 → 提醒關注壓力源，建議增加呼吸練習（4-7-8 呼吸法）
- **正向進步模式：** 指標穩定改善 → 正面肯定，可考慮按計畫進階到下一階段
