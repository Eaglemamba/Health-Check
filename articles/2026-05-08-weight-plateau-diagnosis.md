# 體重平台期診斷與飲食調整方案 — 2026-05-08

**觸發脈絡**：W19（5/3–5/8）體重停在 68.1–68.2 kg，相對 W18 低點 67.8 kg 感覺停滯；BB 起床連 5 天 < 50；大腿酸感無運動仍持續 ≥ 5 天。

**結論先行**：不是平台期，不是吃太多，**是赤字過大 + 步數短缺 + 乳糖負荷 + VitD 不足**的系統性恢復不良。

## ⚠️ 2026-05-08 重大修訂（談話末端揭露關鍵變數）

**新資訊**：使用者目前處於急性 URI（上呼吸道感染）狀態，小朋友先感冒後傳染，主訴「起床一直有鼻涕」。

**這項資訊改寫整份診斷的因果排序**：

| 原假說 | 修訂後 |
|---|---|
| 大腿酸 = VitD 不足 + 礦物質吸收 | **病毒性 myalgia**（IL-6 / TNF-α 直接作用骨骼肌）★★★★★ |
| BB 連 5 天 < 50 = 赤字 cortisol | **免疫系統耗能 + 鼻塞睡眠破碎** ★★★★★ |
| SpO2 nadir 79% = POSA 中度 | **URI 鼻黏膜腫脹放大原 OSA**（混淆變數） |
| Sleep TST 5h35m | **鼻塞 + 起床流鼻涕中斷睡眠** |
| 體重停滯 + 體脂率波動 | **發炎反應滯水 + 活動量降** |

### 所有飲食改造**暫停 7–10 天**

| 原本建議 | 修訂 | 為什麼 |
|---|---|---|
| 熱量上修 / 早餐改造 / Psyllium 改飯後 | **全部暫停**至 URI 完全康復 +3 天 | 生病期間胃腸道反應不穩，無法乾淨驗證假說 |
| 取消訓練 3 天 | **延長至 URI 完全康復後 +3 天** | 病程訓練 → 心肌炎風險 ↑ |
| PSG 預約 | **延後** | 鼻塞會嚴重干擾結果，誤判 OSA 嚴重度 |
| VitD 3000 IU | **保留**（加速感染恢復） | 短期不影響 myalgia，但對免疫有益 |

### URI 期間應做（真正清單）

1. **21:00 前就寢**，睡 ≥ 7.5h，目標 BB 起床 ≥ 50
2. **飲水 3.0 L**（呼吸道發炎水分流失↑）
3. **完全停訓**（含快走），只散步 RPE ≤ 2
4. **蛋白質 ≥ 95g**（免疫球蛋白合成原料）
5. **生理食鹽水洗鼻 ×2/日 + 床頭抬高 30°**
6. **體重數據暫不解讀**（生病滯水 1–2 kg 是常態）

### 紅旗就醫指標

- 發燒 > 38.5°C 連 2 天 → 看診
- 黃綠濃稠鼻涕連 7 天 → 細菌性鼻竇炎
- 胸悶 / 心悸 / 運動耐受度急降 → 立即就診（排除心肌炎）
- 大腿酸 + 尿色變深 + 肌肉無力 → 急診（橫紋肌溶解 / CK 異常）
- BB 連 7 天 < 50 + 主觀 ≤ 2 持續 → 抽血 CBC + CRP

### 預期病程

| 天 | 狀態 |
|---|---|
| Day 1–3 | 鼻塞、流涕、輕微肌肉酸（5/8 落點） |
| Day 4–7 | 症狀高峰、BB 持續低 |
| Day 7–10 | 症狀消退、BB 回升 |
| Day 10–14 | 完全康復、重啟訓練與診斷 |

**體重會在 URI 結束後 3–5 天回到生病前 baseline。**「卡 68」在 URI 期間沒有解讀價值。

## 二、滯水 vs 脂肪：判決

### ❌ 推翻「脂肪太多」
- 全日 1,425–1,600 kcal vs TDEE ~2,200–2,400 → **真實赤字 640–1,000 kcal/日 = 0.6–1.0 kg 脂肪/週**
- 內臟脂肪等級 9.5 連 7 天持平 → 脂肪未堆積
- 體脂率 19.3 → 20.3% 跟飲水量強相關 → BIA 脫水假象

### ❌ 推翻「鈉滯水」
- 全日 1,430–1,830 mg，遠低於 2,300 mg 標準
- 4/22 那種高鈉模式（單餐剝皮辣椒雞胸 800–1,000 mg）不是常態

### ✅ 真正嫌疑（按證據強度）

| # | 因素 | 量級 | 證據 |
|---|---|---|---|
| 1 | **步數短缺 W19**（雨天從 13,475 降至 ~8,000） | 0.6–1.2 kg「該降沒降」 | ★★★★★ |
| 2 | **熱量赤字過大引發 cortisol 滯水**（BB 連 5 天 < 50 印證） | 0.5–1 kg | ★★★★★ |
| 3 | **VitD 不足**（D3K2 從 3000 降至 2000 IU） | 大腿酸感主嫌 | ★★★★ |
| 4 | **乳糖負荷過量**（全日 40–56g vs 耐受 25g） | 0.3–0.7 kg 腸道滯水 + 礦物質吸收干擾 | ★★★★ |
| 5 | **OSA 間歇性缺氧** | 肌肉修復受損 | ★★★ |
| 6 | **無雞胸日蛋白質 85g 不足** | 肌肉自食 | ★★★ |

## 三、反直覺結論：需要**多吃**，不是少吃

> 體重停滯 + BB 持續低 + 體脂率讀數浮動 + 大赤字 + 大腿酸無運動 = **代謝適應前兆**

身體偵測到熱量短缺 → 拉高 cortisol 保水分、降基代、肌肉自食。**這時節食只會更卡。**

## 四、修訂後行動清單

### 立即（今晚就做）
1. **D3K2 補回 3,000 IU**（早餐隨脂肪餐）
2. **鎂 400 mg 睡前**（確認沒漏吃）
3. **椰子水 1 罐 (~330ml) + 鹽 1g**（補電解質）
4. **21:30 強制就寢**（連 7 天）

### 飲食調整（本週開始）
| 變動 | 原因 |
|---|---|
| 熱量上修至 **1,700–1,800 kcal** | 解赤字過大、cortisol 滯水 |
| 無雞胸日晚餐補 **蛋花湯 1 碗或豆腐半盒**（+15g 蛋白質） | 蛋白質保底 ≥ 95g |
| 早餐去羊奶 + 乳清改用水沖 + 加 **1 顆水煮蛋** | 早餐乳糖從 14g → 6g |
| 抹茶牛奶改 **lactose-free 奶 300ml** | 午餐乳糖從 14g → 0 |
| 點心牛奶每日 **≤ 1 杯**，挪到早上 | 控全日乳糖 ≤ 25g |
| 雞胸選**清蒸 / 舒肥原味**（鈉 ~75–400 mg） | 避免高鈉款 |

### 運動調整
- **3 天內取消任何中強度以上運動**，只走路
- **雨天用室內補位 SOP**（已寫入 `templates/pt-rules.md`）
- 雨天硬底線：每日 ≥ 8,000 步

### 醫療追蹤
- **PSG 預約落地**（OSA 是上游，本週首要任務）
- 下次抽血加項：**25(OH)D + 早晨 cortisol + CK**（排除 statin / 肌炎）
- **大腿酸感若 7 天內未消** → 物理治療師評估（觸發 pt-rules.md 5 天規則）
