## 一、為什麼從楔形枕轉 Sims

### Wedge 的本質限制（被動 fidelity）

5/14 起加入頭部楔形枕，5/21 完成 pre/post 自然實驗：

| 指標 | PRE (N=20) | POST (N=8) | Δ |
|------|-----------|-----------|---|
| C1 T90 中位數 | 6.67% | 1.67% | **↓ 75%** |
| C2-C3 T90 | ~12% | ~12% | **0%** |

→ Wedge **只保得住 C1**（前 90 min）。

### Cycle-by-cycle 證據（5/22 baseline）

```
Sleep onset 21:41
C1 (21:41-23:11): T90  0.0%  events 0    ✅ wedge effective
C2 (23:11-00:41): T90 16.7%  events 1   🔴 wedge 失位
C3 (00:41-02:11): T90 20.0%  events 4   🔴 全夜 events 最多
C4 (02:11-03:41): T90  8.9%  events 4   🔴 含 nadir 83% 最深 event
C5 (03:41-05:11): T90 11.6%  events 3   🔴
```

### Mechanism

```
~23:11 起：身體下滑 + 翻身 → wedge 部分失位
~00:41 起：完全翻仰 → wedge 壓在背下 → retroglossal 重力負荷恢復
03:00 ~ 04:00：5/21 user-confirmed 仰臥醒來時段
```

**結論**：wedge 是依賴**外物在位**的介入；睡眠中物件 fidelity 必然衰退。需要轉向**身體本身就鎖死體位**的策略。

## 二、Modified Sims position — 機制與設定

### 體位定義

```
         ╭─頭枕（薄 5-8 cm）
   左肩  ╭───── 上臂（右臂）抱抱枕（前方）
   ─┬─  ╰─ 下臂（左臂）自然垂在身後
    │
    │ 軀幹 ~3/4 prone（半俯，不全俯）
    │
   ─┴─  ╰─ 上腿（右腿）屈膝、跨過抱枕
   左髖  ╰─ 下腿（左腿）微屈、平鋪床面
```

身體軸線 = **3/4 左側 + 1/4 prone**。

### 為什麼鎖得住仰躺

| 機制 | 解釋 |
|------|------|
| 半俯重力 | 舌頭往**前下方**掉（離開咽腔）vs 仰躺往後（堵住咽腔）|
| 骨盆鎖死 | 上腿跨抱枕 → 翻仰需先把腿抬起 → 機械上極難 |
| 不依賴外物 | 體位本身即 anchor，不會 fidelity decay |
| 左側 cardiac | IVC 壓迫 ↓、preload ↓ — 對應 2026-03 ECG 雙心房擴大發現 |

### 文獻支撐

| 研究 | 結論 |
|------|------|
| Cartwright 1984 *Sleep* | 純 lateral → AHI ↓ 50-60% in positional OSA |
| Itasaka 2000 | 左 lateral 略優於右 lateral |
| Morong 2014 *Sleep Breath* | 半俯 (Sims-like) > 純 lateral，再 ↓ 20-30% |
| Ravesloot 2018 *J Clin Sleep Med* | 體位治療對 supine-AHI 主導型反應率 > 70% |

## 三、完整 setup（4-layer 防線）

| Layer | 物件 | 用途 |
|-------|------|------|
| **L1 主防線** | 長型抱枕 120-150 cm | 上臂抱、上腿跨 — 機械鎖死 ~80% 仰躺 |
| **L2 backup** | 楔形枕（從頭下移到背後）| 背後 blocker — 物理阻擋另 10% |
| **L3 警報** | 網球 T-shirt（T4-T6 中胸椎）| 翻過抱枕時觸發不適 — 最後警報 |
| **L4 ground** | 薄頭枕（5-8 cm）| 頸部中位、避免肩部歪斜 |

### 網球 T-shirt 精確定位（不是腰、是肩胛骨之間）

```
       ─┬─ 後頸第七節 (C7) 突出骨點
        │
        │── ★ 球 1：T2-T4（肩胛骨上緣 1/3 連線中點）
   ★    ★
   ★    ★── ★ 球 2：T4-T6（肩胛骨下緣中點，乳頭水平背側）
        │
        │  （可選）球 3：T6-T8（球 2 再下 5-8 cm）
        │
       ─┴─ 腰椎（這裡放球 = 沒效）
```

**穿好後驗證**：平躺 5 秒測試 — 球應該卡在「肩胛骨之間、不在腰、不壓脊突」，仰躺一壓上去就「啊很痛想換邊」= 位置對了。

**為什麼不是腰**：仰躺翻身的力學起點是**肩膀先轉**，肩胛之間有壓力才能在 pivot 點觸發不適 reflex；腰部有壓力時身體已經完成翻仰，太遲。

## 五、Trade-offs（誠實版）

| 風險 | 緩解 |
|------|------|
| 肩 / 髖壓迫 → 痠痛 | 上肩墊薄毯、跨腿抱枕分散；前 3 晚必痠 |
| 與你 3 月 W12-14 上交叉症候群史相關 | 起床做 cat-cow + bird-dog 各 5 次（已在 PT 規則） |
| 抱枕熱（夏天）| 涼感材質或薄布套；只跨腿不抱前胸版本 |
| 起床下背僵 | 醒後不立即起床，做 supine knee-to-chest × 5 |
| 心理上「不自然」 | 第 3 晚起會習慣；女性產科常規體位、不是 weird position |

## 六、Trial 期間注意

1. **凍結期紀律**：5/23-5/27 trial 期間 **不加新介入**（補充品、CPAP 試戴、myofunctional 等都延後）
2. **洗澡時取下手錶**（昨日已建議）— 避免 baseline HR 假性升高
3. **每晨第一件事**：靠記憶填「醒來體位」（不要馬上動，先想）
4. **每晚 wind-down 後** check 4 layers 都到位才上床
5. **Trial 中不討論**：每日紀錄就好，5/27 才一次性結算
