# 補充品與茶飲指南 — 2025 健檢後版本

**基準日期：** 2025-09-17 健檢結果
**優先指標：** LDL 177 / 總膽固醇 234 / 尿酸 8.6 / HbA1c 6.0% / hsCRP 0.302 / 脂肪肝（新增）

---

## 一、茶飲選擇（C4 取 2）

> 選擇原則：最大覆蓋面、最小重疊

| 茶飲 | 選擇 | 理由 |
|------|------|------|
| **抹茶** | ✅ 推薦 | 最廣覆蓋：LDL、總膽固醇、hsCRP、脂肪肝均⭐⭐⭐，管代謝/發炎側 |
| **玉米鬚茶** | ✅ 推薦 | 互補抹茶：尿酸⭐⭐⭐（雙機制）+ 血壓⭐⭐⭐，管排泄/腎臟側 |
| 枸杞茶 | ☐ 次選 | 與抹茶和玉米鬚茶重疊高，若空間允許可加為第三茶 |
| 牛蒡茶 | ☐ 次選 | 益生元效果好，但若益生菌已補充，優先度降低 |

---

## 二、補品組合（互補性最簡方案）

> 選擇原則：已有項目填 TG/hsCRP/尿酸，缺口在 LDL、血壓、維生素 D、睡眠

| 補品 | 狀態 | 優先 | 互補邏輯 |
|------|------|------|---------|
| **魚油 ×4** | ✅ 已有 | 必留 | TG⭐⭐⭐、hsCRP⭐⭐⭐，無可替代 |
| **酸櫻桃膠囊** | ✅ 已有 | 必留 | 尿酸輔助 + 抗炎，和玉米鬚茶協同 |
| **D3K2** | ➕ 新增 | 🔴 必加 | 修正維生素 D 28.8（不足），唯一能解決此問題的 |
| **鎂（甘胺酸鎂）** | ➕ 新增 | 🔴 必加 | 血壓⭐⭐⭐ + 睡眠改善，睡眠是你的最大弱點 |
| **益生菌** | ➕ 新增 | 🟠 建議 | LDL⭐⭐ + HbA1c⭐⭐，配合玉米鬚茶/牛蒡菊糖協同 |

**最簡核心組合（5 項）：** 魚油 + 酸櫻桃 + D3K2 + 鎂 + 益生菌

## 四、劑量與時機表

| 項目 | 研究有效劑量 | 建議實際劑量 | 時機 | 注意事項 |
|------|------------|------------|------|---------|
| **抹茶** ✅ | EGCG 200–500mg（約 3–7g 粉） | 2g/次，1–2 次/天 | 早上，10:00 前 | 含咖啡因 ~70mg/g；下午後不喝；睡眠問題者嚴格執行 |
| **魚油** ✅ | EPA+DHA 2–4g/天（降TG）；1–2g（心血管） | ×4 粒/天（確認每粒 EPA+DHA 含量） | 餐後 | 高劑量輕微影響 LDL，注意魚油品質（rTG 形式最佳）|
| **益生菌** ✅ | L. reuteri 9億 CFU/天（降LDL最佳菌株） | 1–10 億 CFU | 早餐前或睡前 | 與玉米鬚茶菊糖同天服用協同效果最佳 |
| **鎂** ✅ | 300–400mg/天 | 200–400mg，從低劑量開始 | 睡前 | 選甘胺酸鎂（Magnesium Glycinate）或蘋果酸鎂；氧化鎂吸收差，不建議 |
| **D3K2** ✅ | D3：2000–4000 IU（目前不足）；K2（MK-7）：100–200mcg | D3 2000 IU + K2 100mcg | 含脂肪餐後 | 脂溶性，需搭配油脂吸收；K2 MK-7 優於 MK-4 |
| **酸櫻桃** ✅ | 相當於 480ml 原汁/天 | 膠囊 1000–2000mg | 早或睡前 | — |
| **玉米鬚茶** ✅ | 乾燥 10–15g / 500ml 水 | 10–15g，1–2 杯 | 早上，14:00 前結束 | 強利尿，下午後喝直接加重夜尿問題 |
| 枸杞茶 ☐ | 乾果 10–30g/天 | 20g | 下午或晚上 | 若選為第三茶可加回 |
| 牛蒡茶 ☐ | 乾根 5–10g / 500ml 水 | 5–10g | 早上或中午，14:00 前 | 輕度利尿，配益生菌效果最好 |

## 五、建議每日時程

```
起床後（空腹）
  玉米鬚茶 10–15g / 500ml        尿酸排泄 + 血壓

早餐
  抹茶 2g（10:00 前喝完）         LDL + hsCRP + 脂肪肝
  D3K2（含脂早餐後）              維生素 D 修正
  益生菌                          LDL + 腸道菌叢

午餐後
  魚油 ×4                        TG + hsCRP

下午（14:00 前）
  [可選] 牛蒡茶或枸杞茶

睡前
  鎂 200–400mg                   血壓 + 睡眠
  酸櫻桃膠囊 1000–2000mg         尿酸 + 抗炎

─────────────────────────────────
17:00 後：只喝白水，其他全停
─────────────────────────────────
```

## 六、預期效果與時程

| 時間 | 可能看到的改善 |
|------|--------------|
| 4–6 週 | TG 下降、hsCRP 達標（≤0.300）、血壓穩定 |
| 8–12 週 | 尿酸開始明顯下降、維生素 D 達標、LDL 小幅改善 |
| 3 個月 | HbA1c 改善可見、尿酸落點確認、LDL 落點確認 |
| 3 個月後 | 根據 LDL 落點決定是否討論 statin |

**誠實的預期上限（無 statin）：**
- LDL：177 → 約 152–162（仍高於目標 130）
- 總膽固醇：234 → 約 204–214（仍高於目標 200）
- 尿酸：8.6 → 約 6.8–7.6（有機會達標，非保證）
- hsCRP：0.302 → 低於 0.300（最容易達標）
