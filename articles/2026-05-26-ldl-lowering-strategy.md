## 二、降 LDL 對本案的必要性：**高**

### 核心原理：風險因子相乘，不是相加

單一 LDL 154 在無其他風險的 37 歲或許算中度；但本案為：

> LDL 154 + HDL 39 + 高血壓 + 糖尿病前期 + 高尿酸 + 疑似 OSA + ECG 已現 LVH

這是**代謝症候群叢集 + 已出現器官受損跡象**。在此 context 下降 LDL 為必要：

1. **LDL 為動脈硬化之因果因子**（Mendelian randomization + RCT，醫學證據等級最高之一），非僅相關
2. **年齡 37 歲 → 累積暴露（mg × 年）關鍵**：越早控制，終生 ASCVD 風險下降幅度越大
3. **HDL 低 + LDL 高並存** → 膽固醇逆運輸不足，雙重不利
4. **ECG 已現 LVH** → 心血管系統已承壓（主因高血壓，血脂控制為整體策略一環）

---

## 三、⚠️ 紅旗：必須先就醫，不能只靠飲食

### 1. ECG 異常需心臟科評估
「前壁 ST 上升 >0.20mV in V1-V4」+ LVH + 雙心房擴大 + 第二期高血壓的組合，應找心臟科進一步檢查（心臟超音波等）。非飲食可解決範疇。

### 2. 飲食單獨可能不足以達標
- Portfolio Diet 全做：LDL **-17%** → 154 × 0.83 ≈ **128 mg/dL**
- 本案風險叢集，醫師可能設定目標 **<100 甚至 <70**
- 128 仍未達標 → 需與醫師討論是否需 statin（風險叢集 + ECG 變化使藥物門檻降低）

> **飲食是必做基礎，但以本案風險等級，不應視為唯一手段。**

## 四、降 LDL 多槓桿策略（依證據與效果排序）

### 框架：Portfolio Diet（四支柱疊加 → LDL -17%）

Chiavaroli 2018 meta-analysis：黏性纖維 + 植物固醇 + 堅果 + 植物蛋白疊加 → LDL **-17%（-0.73 mmol/L）**，並降 ApoB、CRP、血壓，效果近低劑量他汀。[DOI: 10.1016/j.pcad.2018.05.004](https://doi.org/10.1016/j.pcad.2018.05.004)

| 支柱 | 現狀 |
|------|------|
| ① 黏性纖維（psyllium 10g + 大麥 β-glucan） | ✅ 已做 |
| ② 植物固醇 | ❌ 待加 |
| ③ 堅果（南瓜籽 30g） | 🔶 部分 |
| ④ 植物蛋白（大豆） | ❌ 待加 |

### Tier 1（大槓桿）

**1. 減飽和脂肪 → 換不飽和（PUFA/MUFA）** — 最強飲食槓桿
- Cochrane（Hooper 2020，~59,000 人）：減飽和脂肪 → 心血管事件 **-21%**，降幅與 LDL 下降成正比 [DOI: 10.1002/14651858.CD011737.pub2](https://doi.org/10.1002/14651858.CD011737.pub2)
- 實作：少紅肉肥肉/奶油/椰子油/棕櫚油 → 換橄欖油、芥花油、堅果、酪梨、深海魚。重點是「換對油」非「減總脂肪」

**2. 植物固醇/固烷醇 2–3 g/日** → LDL **-6 ~ -12%**
- Ras 2014（124 研究）：劑量-反應在 ~3 g/日達 -12% 平台 [DOI: 10.1017/S0007114514000750](https://doi.org/10.1017/S0007114514000750)

**3. 黏性纖維（已做，主力 psyllium 10g）** → LDL **-7 ~ -13 mg/dL**
- Jovanovski 2018（psyllium 10.2g → -0.33 mmol/L）[DOI: 10.1093/ajcn/nqy115](https://doi.org/10.1093/ajcn/nqy115)
- 注意「平台效應」：3–4 週達較低平台後維持，非每日累加；停則回基線

### Tier 2（中小槓桿）

**4. 大豆蛋白 25 g/日**（豆腐、豆漿、毛豆、天貝）→ 小幅降 LDL + 取代肉類雙重益
**5. 堅果 30–45 g/日**（杏仁、核桃、榛果）→ 小至中度
**6. 減重**（進行中，67.6kg 下降）→ 小幅降 LDL
**7. 其他小槓桿**（Schoeneck 2021）：亞麻籽、酪梨、薑黃、綠茶、豆類 [DOI: 10.1016/j.numecd.2020.12.032](https://doi.org/10.1016/j.numecd.2020.12.032)

### ⚠️ 現有 protocol 注意點

| 在用項目 | 對 LDL 影響 |
|---------|------------|
| 魚油 ×4 | 強降 TG，但**可能小幅升 LDL**（高劑量 EPA/DHA）— 為降 TG 工具非降 LDL 工具 |
| 南瓜籽 30g | ✅ 含植物固醇 + PUFA |
| 菇蕈 100-130g | ✅ β-glucan |
| 洛神花茶 | 🔶 部分研究示小幅降脂 |

## 五、植物固醇含量較多的食物

**重要前提**：天然食物的植物固醇量**不足以達治療劑量**。一般飲食約 300–500 mg/日，有效降 LDL 需 **2–3 g/日**，治療劑量基本只能靠強化食品或補充品。

天然來源（每 100g 約值）：

| 食物 | 植物固醇 |
|------|---------|
| 未精製植物油（米糠油、玉米油、芝麻油） | 800–1000 mg |
| 小麥胚芽 | ~400 mg |
| 芝麻、葵花籽 | 400–700 mg |
| 南瓜籽（已吃 30g） | ~265 mg |
| 開心果 | ~280 mg |
| 杏仁、核桃 | 120–200 mg |
| 黃豆 / 豆類 | 100–160 mg |
| 酪梨 | ~75 mg |
| 花椰菜、抱子甘藍 | ~40 mg |

**實務**：
- 天然食物路線：南瓜籽（已做）+ 芝麻 + 堅果 + 未精製油 + 豆類 → 約 500–800 mg/日，達不到 2g 但對 Portfolio 有貢獻
- 治療劑量 2g：需植物固醇強化產品（固醇強化乳瑪琳/優酪乳飲）或補充品

## 七、行動優先序

1. **🔴 先看心臟科**：帶 ECG + BP + 血脂數據（ECG 異常 + 第二期高血壓優先於飲食）
2. **🟡 飲食基礎**：補齊 Portfolio（減飽和脂肪換不飽和、加大豆蛋白、加堅果/芝麻、考慮植物固醇強化品）
3. **🟡 控血壓 + OSA**：BP 153/88 + LVH 可能比 LDL 更急（PSG 追蹤中）
