### 腰圍變化的量化解讀（嚴謹版）

| 1 cm 腰圍變化（男性）| 量級 | 占比 |
|---|---|---|
| 皮下腹部脂肪 | 0.3–0.6 kg | 50–70% |
| **內臟脂肪 (VAT)** | **0.15–0.4 kg** | 25–40% |
| 水分 + 肝醣 + 腸道內容物 | 0.05–0.2 kg | 10–20% |
| 骨骼肌（極少）| < 0.05 kg | < 5% |
| **腹部總脂肪減量** | **0.5–1.0 kg** | 100% |

**研究依據**：
- Smith et al. (2012) Obesity：男性 1 cm 腰圍 ≈ 4–7 cm² VAT 截面積（L4–L5）
- Goran 計算式：VAT 質量 = 截面積 × 0.94 g/cm³ × ~10 cm 縱深
- Stanforth et al. (2004)：減重期 VAT vs SAT 比例 30–50% / 50–70%（apple-shape 偏高至 40–50%）

**精確性說明**：以上為人群均值推估。個人精確 VAT 量化仍需 DEXA / CT。對 apple-shape 體型者（你），VAT 占比偏高，1 cm 腰圍實際 VAT 減量更可能落在 0.25–0.4 kg。

**你 6 週腰圍 84 → 83 cm 的實際意義**：
- 腹部總脂肪：−0.5–1.0 kg
- 其中內臟脂肪：−0.25–0.4 kg
- Tanita 內臟等級從 9.5 → 9.5：演算法解析度粗（每階 ~10 cm² ≈ 0.5 kg VAT）+ 落後 4–8 週，看不到 0.3 kg 級變化
- 下一個跳級點：內臟脂肪再減 0.5–0.7 kg → 預計腰圍 81–82 cm 時 Tanita 顯示 9.0

| 3. 臉型 | 鏡子裡比平常圓、下顎線模糊 |
| 4. 襪痕 | 昨晚襪痕脫襪後 > 5 分鐘仍清晰 |
| 5. 手指僵感 | 早起握拳緊繃需活動才鬆 |

→ **3 項以上陽性 = 全身性滯水確認**

### 按壓小腿（Pitting edema）何時做

平時不必，**只在以下情境作為紅旗篩檢**：
- 突發單側小腿腫痛 → DVT 排除
- 雙側下肢逐漸水腫 + 喘 → 心衰排除
- 尿少 + 水腫 → 腎臟排除

正常 URI 滯水**通常測不到 pitting edema**（要 ≥ 3 kg overload 才看得到凹陷）。

### 診斷流程改進

1. **體重停滯 / 恢復不良診斷的第一個篩選問題**：「最近 14 天內有無感冒、發燒、感染病程？家人是否生病？」  
   → 計畫寫入 `templates/daily-command.md` 開頭。

2. **BIA 體脂率讀數變動**單獨不能作為診斷依據；必須交叉驗證**腰圍 + WHtR + Navy 公式**才能判斷真實 BF%。

3. **「卡關」感受**多半是 anchoring bias — 把 outlier 低點當成新 baseline。**5–7 天移動平均**才是真 baseline。

4. **多因子診斷時**，先問「有沒有一個簡潔因子能解釋全部？」（Occam's razor）。本案 URI 一條鏈解釋掉 6 項症狀，遠優於 4 因子加總。

5. **使用者報告的 supplement 劑量變動**（D3K2 從 3000 → 2000 IU）必須當作獨立變數記錄，不要漏掉。

## 附錄 A：發炎反應滯水的證據強度

機制鏈每一環都站得住（教科書 / 共識級證據），但**「輕症 URI 滯水多少 kg」沒有專門 RCT 量化**：

| 環節 | 證據等級 |
|---|---|
| URI 啟動先天免疫 | 確定 |
| 細胞激素 IL-1β / IL-6 / TNF-α 釋放 | Harrison's 內科學 |
| 微血管通透性↑ → 第三間隙液體積聚 | ★★★★★ ICU 共識 |
| ADH（抗利尿激素）分泌↑（部分 IL-6 介導 + 發燒） | ★★★★ |
| Aldosterone↑（急性壓力反應 + 交感活化） | ★★★★ |
| 腎小管 Na + 水再吸收 ↑ | ★★★★★ |
| 活動量降 → 肌肉幫浦失效 | ★★★★ |

**輕症 URI 滯水 0.5–1.5 kg 是合理推估**，不是 N=200 meta-analysis 的結論。

## 附錄 B：艾來（desloratadine）作用範圍

第二代 H1 受體拮抗劑：**症狀壓制，不抗病毒**。

| 來源 | 機制 | 對你的占比 |
|---|---|---|
| 過敏性鼻炎（既有） | 塵蟎等過敏原 → 肥大細胞 → 組織胺 | ~50% |
| URI 觸發 | 病毒誘發肥大細胞脫顆粒 + 嗜酸性球活化 | ~30% |
| 純病毒症狀 | 不受 H1 拮抗劑影響 | ~20% |

→ 艾來壓下你 ~80% 的鼻部症狀，但**全身性發炎滯水（aldosterone / ADH 路徑）艾來不管**。

**間接療效真實存在**：鼻塞↓ → 睡眠↑ → BB 恢復↑ → SpO2 改善（5/8 nadir 從 79% 回到 87%）。

**注意**：症狀緩解 ≠ 病毒已清除；不能因「好多了」就回去訓練。
