## 四、給你的全家 Top 選擇（對齊 UA / BP / LDL）

| 用途 | 首選 |
|------|------|
| 每日蛋白主錨 | **義式經典雞胸（原味，24.5g）** |
| 想要一餐完整 | **健身G肉餐盒（低鹽雞胸，29g）** |
| 飲品蛋白 | 光泉無加糖濃豆漿 / 黑豆漿 |
| 蛋類 | 溫泉蛋（鈉低於茶葉蛋）|
| 碳水 | 蒸地瓜 |
| **避免** | 沙嗲雞胗（內臟高普林）、蒜味滷味（加工高鈉）|

**全家 vs 7-11 你怎麼選**：兩家義式雞胸蛋白接近（全家 24.5 / 7-11 熏雞胸 22.6），全家多了「**健身G肉餐盒（低鹽醃漬）**」這個營養師監製的完整低鈉餐選項，是它相對 7-11 的亮點；7-11 則在毛豆（鹽味 315mg）與品項廣度上強。**鈉與口味原則兩家通用——選原味、看標示、嫌鹹是好事。**
