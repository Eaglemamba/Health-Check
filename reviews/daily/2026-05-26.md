## 補充:攝影機第二批觀察 —— 微覺醒動作群 + 過敏性鼻炎 + 張口呼吸

再次檢視整夜影像,觀察到以下動作群:
- 手揮來揮去、翻身、腳伸直
- **手抓鼻子 + 鼻子癢 + 鼻嘴一起動**
- **張口呼吸**
- 念念有詞(somniloquy)

### 關鍵重新框架:動作是「微覺醒」的下游表現,非各自獨立的病

睡眠中的動作 / 翻身 / 發聲,絕大多數是 micro-arousal(3-15 秒短暫覺醒)的下游表現。要問的不是「我有幾種病」,而是「什麼在製造這些微覺醒」。

### 統一假說(證據鏈完整)

```
過敏性鼻炎(鼻癢/抓鼻/5-20 洗鼻噴嚏)
  → 夜間鼻塞 → 被迫張口呼吸(影像確認)
    → 下顎舌根後墜 + 失鼻腔 NO → 氣道窄、易塌陷
    → 疊加被蓋頭 rebreathing
      → SpO2 desat + 頻繁微覺醒
        → 動作群(揮手/伸腳/碎念/抓鼻)
          → 睡眠片段化 → Garmin「0 中醒」但恢復感 3/5
```

### 三條證據匯流指向過敏性鼻炎(可治療的上游源頭)

1. 5/20 洗鼻當下大量噴嚏(已標記疑 allergic rhinitis / NAR)
2. 攝影機:睡眠中鼻癢 + 鼻嘴一起動
3. 攝影機:手抓鼻子 + 張口呼吸

### 解開矛盾:Garmin「中途醒來 0 次」vs 恢復感 3/5

- Garmin 只計「完全清醒」,不計微覺醒
- 影像中大量動作 = 微覺醒,落在 Garmin 偵測門檻以下
- 結論:問題可能不是「睡得不夠久」,而是「睡得不夠連續(深度片段化)」

### 逐項定性

| 觀察 | 定性 | 對睡眠影響 |
|------|------|----------|
| 手揮 / 翻身 | 正常姿勢調整 + 微覺醒後動作 | 過頻則為片段化指標 |
| 腳伸直 | 需看是否週期性 | 每 20-40 秒成串 → 疑 PLMD,查 ferritin |
| 鼻癢 / 抓鼻 / 鼻嘴動 | 過敏性鼻炎徵象 | **上游主因,可治療** |
| 張口呼吸 | 鼻塞下游 + 反過來加重氣道窄 | 加重打鼾 / OSA 傾向 |
| 念念有詞 | somniloquy,多半良性 | 標記淺眠 / 覺醒邊緣 |
