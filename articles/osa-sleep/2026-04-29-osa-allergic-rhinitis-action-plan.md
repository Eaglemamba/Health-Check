# OSA + 過敏性鼻炎 整合行動方案

**建立日期**：2026-04-29
**觸發事件**：Garmin SpO2 連 3 晚 < 88%（82 → 81 → 79，最低點 02:21 79%），合併晨起必打噴嚏、夜間鼻塞
**個案表型**：非肥胖（BMI ~21.5）+ NREM-predominant OSA + 過敏性鼻炎主因（塵螨高度懷疑）
**文件性質**：前瞻性指南；後續 PSG 結果與介入效果出爐後改版另存

---

## 〇、核心因果鏈（為什麼問題遲未改善）

```
枕頭裸露（無防螨套）
  + 床墊保潔墊「久未洗」（防護已失效）
  + 冷氣機（去年新機、沒用幾次 → 內部殘水長黴可能）
  + 室內濕度 50-55%（塵螨繁殖最佳區間）
  + 室內外溫差大、冷風直吹頭部
  ────────────────────────────────────
  = 整夜過敏原暴露 + 鼻黏膜持續發炎
  = 晨起必打噴嚏 + 夜間鼻塞峰值（凌晨 2-4 點）
  = 強迫口呼吸 → 舌根 / 咽部側壁塌陷
  = OSA 加重 → SpO2 desaturation（最低 79% @ 02:21）
  = Sleep Score 64 / Body Battery 58 / 主觀恢復 3
```

**結論**：不是 OSA 治不好，是**過敏原暴露源沒斷**。一個一個堵漏洞，4-6 週後 SpO2 應顯著改善。

## 一、表型確認 — 你不是典型 OSA

| 你的特徵 | 一般 OSA | 治療意義 |
|---|---|---|
| BMI ~21.5（非肥胖） | 多 BMI > 25 | 約 25% OSA 患者 BMI 正常；需 phenotype-driven 治療，不能套用「減重 + CPAP」流程 |
| Desat 出現於 Deep + Light，REM 反而正常 | 多為 REM-dependent | NREM-OSA 占 OSA 群 60.7%（Taiwan 三總研究 2022） |
| 體脂 19.3% / 內臟脂肪 9.5 達標 | 多腹部肥胖 | 減重幾無 leverage，需走 upper airway muscle / 解剖 / 姿勢路徑 |
| 晨起必打噴嚏 + 夜間鼻塞 | 不一定 | **過敏性鼻炎為 OSA 直接放大器**，先處理鼻部可能大幅改善 desaturation |

## 三、五層治療金字塔（從根治到症狀控制）

```
       ┌────────────────────────┐
       │ 第 5 層：手術           │ ← 結構性失敗才考慮
       ├────────────────────────┤
       │ 第 4 層：免疫療法 SLIT  │ ← 唯一「根治」選項
       ├────────────────────────┤
       │ 第 3 層：藥物階梯       │ ← 抗發炎 + 抗組織胺
       ├────────────────────────┤
       │ 第 2 層：環境控制       │ ← 移除過敏原（最高 ROI）
       ├────────────────────────┤
       │ 第 1 層：診斷與分型     │ ← 知道過敏什麼
       └────────────────────────┘
```

### 第 1 層：診斷

- **MAST 過敏原檢測 36 項**（自費 NT$2,000-5,000）— 必含塵螨 + Aspergillus + Penicillium + Cladosporium + Alternaria
- **皮膚點刺試驗 SPT** 替代選項
- **PSG 多項睡眠檢查** — 胸腔內科或耳鼻喉睡眠門診
- **耳鼻喉鼻內視鏡 + 鼻通氣評估**

### 第 2 層：環境控制（最高 ROI、無副作用）

#### 塵螨

| 介入 | 標準 | 對你的執行 |
|---|---|---|
| 防塵螨枕頭套 | 孔徑 < 10 μm、全包式拉鍊 | **本週必補**（目前裸露） |
| 防塵螨保潔墊 / 床墊套 | 同上 | **已有但久未洗 → 60°C 熱水洗 + 烘乾** |
| 防塵螨被套 | 同上 | **本週補上** |
| 床單 / 枕巾 | 每週 60°C 熱水洗 | 建立習慣 |
| 保潔墊本身洗滌 | **每 1-2 個月 1 次 60°C** | **新建習慣**：每月第一個週日 |
| 棉被 | 每月 60°C 洗或烘乾機 60°C 60 min | 建立 |
| 枕頭內芯 | 每 3 個月 60°C 烘 60 min；> 2 年直接換 | 評估枕頭年齡 |
| 室內濕度 | **45-50%**（塵螨在 > 50% 大量繁殖） | 用獨立溫濕度計放枕頭旁實測 |
| 絨毛玩具 / 厚地毯 / 布沙發 | 移出臥室 | — |
| HEPA 空氣清淨機 | CADR > 250、24h 運轉 | 可選（NT$5,000-12,000） |

#### 黴菌（冷氣去年新機、沒用幾次 → 內部殘水長黴高風險）

| 階梯 | 動作 | 頻率 / 成本 |
|---|---|---|
| 1 | 使用者自洗濾網 | 每 2 週、0 |
| 2 | 冷氣噴霧清潔劑 | 每 3-6 月、NT$200-500 |
| 3 | **專業到府深度清洗**（蒸發器、葉輪、滴水盤） | **本週必排**、NT$1,500-3,000/台 |
| 4 | 每次關機前切「送風 30-60 分」吹乾蒸發器 | **每次關機**、0 |
| 5 | 不開冷氣季每月通電運轉 30 分鐘維持乾燥 | 月度、0 |

#### 其他

- 冷氣風向上掃**不對頭部直吹**
- 室溫設 **25-26°C**（不低於 24°C，減少室內外溫差）
- 戒煙 / 避免二手煙

### 第 3 層：藥物階梯

#### Step 1：日常維持

- **第二代抗組織胺**：Fexofenadine 60-180 mg / Loratadine 10 mg / Cetirizine 10 mg
- 生理食鹽水洗鼻早晚各 1 次

#### Step 2：中度持續性（**目前該層**）

- **鼻內類固醇 — 過敏性鼻炎首選與基石** ★★★★★
  - Mometasone（Nasonex）/ Fluticasone（Flixonase）/ Budesonide（Rhinocort）
  - 每天噴不要間斷；1-2 週累積到完整效果
  - 局部作用、長期安全（與口服類固醇完全不同）
- **+ 第二代抗組織胺**

#### Step 3：中重度

- **複方鼻噴**：Dymista（Fluticasone + Azelastine）/ Ryaltris（Mometasone + Olopatadine）
- **+ Montelukast 10 mg QD 睡前**（合併氣喘者特別有效）

#### Step 4：難治性

- 短期口服類固醇（5-7 天）
- 生物製劑（Omalizumab，重症才用）

#### 嚴格禁忌（會加重 OSA）

- **第一代抗組織胺**：Diphenhydramine、Chlorpheniramine（市售感冒藥常見）— 鎮靜 + 降 arousal threshold
- **鼻內血管收縮劑連續 > 5 天**：Otrivin、Afrin → 反彈性鼻塞惡化
- **安眠藥、酒精**

### 第 4 層：免疫療法 SLIT — 唯一根治選項

#### 為什麼對你最關鍵

- 第 1-3 層都是「控制症狀」，停藥就復發
- SLIT 是 WHO/EAACI/ARIA 認可的「修改疾病進程」唯一介入
- 療程 3-5 年，效果可維持 7-12 年甚至終身
- 對「塵螨單一過敏 + 中重度 + 影響生活品質（OSA）」最具 cost-effectiveness

#### SLIT vs SCIT

| 項目 | SLIT 舌下 | SCIT 皮下 |
|---|---|---|
| 形式 | 每天舌下含錠 / 滴劑 | 每月診所打針 |
| 嚴重副作用 | 極低（口腔搔癢） | 全身性過敏反應風險 |
| 療程 | 3-5 年 | 3-5 年 |
| 費用（台灣） | NT$3,000-5,000/月，全程 NT$10-20 萬 | 較便宜但時間成本高 |
| 健保 | 部分品項（Acarizax）有條件給付 | 較少 |

#### 台灣可用品項

- **Acarizax**（Dermatophagoides 標準化錠，TFDA 核准塵螨用）
- **Staloral**（滴劑型）

#### SLIT 適合性檢核

- [ ] MAST 確認塵螨陽性 ≥ Class 3
- [ ] 中重度持續性過敏性鼻炎 ✓
- [ ] 標準藥物效果不佳或希望減藥
- [ ] **影響生活品質（OSA）** ✓
- [ ] 願意 3-5 年療程
- [ ] 無嚴重氣喘失控、無免疫疾病

→ **目前已符合 2-3 項**，PSG + MAST 出爐後應正式評估。

### 第 5 層：手術（藥物與免疫療法均失敗才考慮）

| 手術 | 適應症 |
|---|---|
| 下鼻甲縮減（射頻 / 電燒） | 下鼻甲肥大導致鼻塞 |
| 鼻中膈成形術 | 鼻中膈彎曲 |
| 鼻竇內視鏡手術 FESS | 慢性鼻竇炎合併鼻瘜肉 |

**手術不能根治過敏體質**，只解決結構性鼻塞。**SLIT 仍是真正的根治路徑**。

## 四、OSA 同步介入（鼻部以外）

### 立即（今晚開始，零成本）

1. **強制側睡**：穿合身 T-shirt、背部口袋縫 1-2 顆網球（網球法）
   - 進階：vibrotactile 裝置（NightBalance / Somnibel）— MDA 70.5% vs 網球法 48.6%
   - **不要**用斜枕（對側睡者會強迫變仰睡）
2. **床頭抬高 30°**（床腳墊 4-6 吋，不是抬枕頭）
3. **睡前 4 hr 禁酒、禁安眠藥、禁鎮靜性抗組織胺**

### 1-3 個月可做

4. **口咽肌訓練 Myofunctional Therapy**（2025 meta-analysis：12 週可使中度 OSA AHI 降 ~50%）
   - 每日 10 分鐘 × 3 次
   - 舌頂上顎 / 舌外推 / 軟顎抬升「啊—」音 / 吹氣球 / 咬合咀嚼
5. **不使用 mouth tape**（2025 PLOS One systematic review：對有鼻阻塞者有窒息風險，**對你絕對禁忌**）
6. **維持運動量**：≥ 7 hr/週運動者 OSA odds ratio 0.33

### PSG 確診後治療選項（依嚴重度與表型）

| AHI | First-line | 適合你的考量 |
|---|---|---|
| 5-15（輕度） | MAD + 姿勢治療 + MT | **非肥胖 + Asian craniofacial → MAD 是合理首選**，adherence > CPAP |
| 15-30（中度） | MAD 或 CPAP 二擇 | 看 endotype 與容忍度 |
| > 30（重度） | CPAP first-line | 無妥協空間；不耐 → HGNS（Inspire 植入式舌下神經刺激器） |

JACC 2024 RCT：MAD 在降血壓不劣於 CPAP，對你（非肥胖、亞洲面型、需高 adherence）是強候選。

## 五、整合執行清單（本週優先）

### 今晚（30 分鐘可完成）

- [ ] 保潔墊 + 枕頭套 + 被套**全部 60°C 熱水機洗 + 烘乾**
- [ ] 冷氣風向上掃、溫度設 25-26°C
- [ ] 拆冷氣濾網水洗（明早晾好再裝）
- [ ] 縫網球側睡 T-shirt
- [ ] 床頭抬高 4 吋
- [ ] 開機前先聞氣味、開機後 30 分內觀察鼻部反應

### 明日（採購與用藥啟動）

- [ ] 藥局：指尖血氧機（NT$1,000-2,000）、洗鼻壺 + 生食鹽包、Fexofenadine 180 mg
- [ ] 網購下單：**防塵螨枕頭套（必）+ 被套（建議）**、獨立溫濕度計
- [ ] 預約家電行**到府洗冷氣**（本週末或下週）
- [ ] 啟動：**早晚洗鼻 + 睡前 1 hr Fexo 180 mg**

### 本週內（5/5 前）

- [ ] **過敏免疫科或耳鼻喉過敏專科掛號**
  - 訴求：「**過敏性鼻炎合併 OSA 紅旗（SpO2 連 3 晚 < 88%、最低 79%），請評估鼻部結構 + 過敏 + 排 PSG，並考慮鼻內類固醇處方與 SLIT 適合性**」
- [ ] **PSG 預約**（胸腔內科或耳鼻喉睡眠門診）
- [ ] 防塵螨寢具到貨後立即換上
- [ ] 收集 3-5 晚血氧機數據
- [ ] 鼻塞日記：哪邊塞、流涕性狀、姿勢相關性

### 1-4 週（5/6-5/27）

- [ ] MAST 結果回饋 → 確認塵螨等級 + 黴菌等級
- [ ] 鼻內類固醇開始用（1-2 週起效後可逐步減 Fexo 劑量）
- [ ] 環境控制完整建置（防螨套全套 + 濕度 45-50% + 冷氣專業洗）
- [ ] **目標：SpO2 最低 > 88%、無單晚 < 85%**

### 1-3 個月

- [ ] 與專科醫師討論 SLIT（若塵螨陽性）
- [ ] PSG 結果出爐 → 確認 OSA 嚴重度與是否需 MAD/CPAP
- [ ] 重新評估：**鼻部解決後，OSA 是否自動降階**

### 6 個月評估點

- 若 SLIT 啟動 + 環境控制良好 → 鼻部症狀降至偶發、輕微
- 鼻部根治後 OSA 仍存在的部分才是「真正純結構性 OSA」，治療目標清晰

### 3-5 年（SLIT 完成後）

- 過敏性鼻炎理論上可長期緩解或根治
- 不再每天用藥
- OSA 的鼻部成因永久解決
- **這是真正的根本解決**
