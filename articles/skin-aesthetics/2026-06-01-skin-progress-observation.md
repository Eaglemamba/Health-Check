## 四、Vit C 精華加入決策 — RCT 證據

### 為什麼 Vit C 精華值得加入

外用 Vit C 與口服 Vit C **不是同一路徑**：
- 口服 Vit C → 血漿 → 各組織分配；皮膚 ascorbate 濃度受限
- 外用 Vit C → 直接局部高濃度 → 真皮 prolyl/lysyl hydroxylase cofactor → 膠原合成

口服 + 外用組合在皮膚 ascorbate 濃度上是疊加而非取代（Pinnell 2001, Lin 2003）。

### 主要 RCT 與機轉證據

| 研究 | 設計 | 主要結果 |
|------|------|---------|
| **Pinnell 2001**（Dermatol Surg）| 5% L-AA × 12 週 vs vehicle | 顯著改善光老化臨床評分 + 切片證實新生膠原 |
| **Humbert 2003**（Exp Dermatol）| 5% L-AA × 6 個月 vs placebo | 真皮膠原密度 ↑、光老化評分改善 |
| **Lin 2003**（Dermatol Surg）| 15% L-AA + 1% Vit E × 4 天 | **光防護 4-8 倍**（紅斑 + sunburn cell 減少） |
| **Lin/Pinnell 2005**（J Invest Dermatol，「Duke formula」）| 15% L-AA + 1% Vit E + 0.5% ferulic acid | **穩定性 ↑ + 光防護 doubled 到 8 倍**；C E Ferulic 2005 上市基礎 |
| **Murray 2008**（JAAD）| C E Ferulic UV 刺激後切片 | 阻斷 thymine dimers、p53 表達、發炎 markers |
| **Correia 2023 systematic review**（J Cosm Dermatol）| Vit C 在 melasma + 光老化的系統性回顧 | 多 RCT 一致顯示光老化改善；現有證據以 ≤ 10% 為主，20% 額外效益不顯著 |

### 「Duke formula」黃金組合（Pinnell 在 Duke 大學的研究）
- **15% L-ascorbic acid + 1% α-tocopherol + 0.5% ferulic acid**
- pH < 3.5（L-AA 穩定 + 吸收條件）
- 三者協同：C 抗水溶 ROS、E 抗脂溶 ROS、ferulic 穩定 C + 自身抗氧化
- 室溫下儲存 1 年 L-AA 穩定 > 90%
- **這是 SkinCeuticals C E Ferulic 的 2005 上市配方**

### 為何 Vit C 必須是 L-ascorbic acid 而非衍生物

| 形式 | 活性 | 刺激度 | 穩定度 |
|------|------|--------|--------|
| **L-ascorbic acid (L-AA)** | ⭐⭐⭐ 直接活性 | 中-高（pH 低）| 低（需暗瓶 + 抗氧化系統穩定）|
| Sodium ascorbyl phosphate (SAP) | ⭐⭐ 需體內轉化 | 低 | 高 |
| Magnesium ascorbyl phosphate (MAP) | ⭐⭐ | 低 | 高 |
| Ascorbyl glucoside | ⭐ | 極低 | 高 |
| Tetrahexyldecyl ascorbate (THD) | ⭐⭐⭐ 脂溶 | 低 | 高 |

→ **L-AA 是 RCT 主要使用形式，效力最強但需正確配方穩定**。衍生物適合敏感肌入門但效果較弱、缺乏 RCT 累積。

## 六、對你的推薦：**La Roche-Posay Pure Vitamin C10** ⭐

理由：
1. **品牌一致性**：你已用 La Roche-Posay UVMune 400 + Cicaplast B5 → 同品牌配方相容性最高、屏障刺激風險最低
2. **10% L-AA**：RCT 主流劑量，Correia 2023 review 顯示 ≤ 10% 與 15-20% 效果差異不顯著但刺激明顯較低
3. **配方含 madecassoside + neurosensine**：與 Cicaplast B5 機轉重疊，溫和適合 retinol 同期使用
4. **價格合理**：~ NT$ 1,400/30 mL，撐 2-3 個月

**不選 SkinCeuticals C E Ferulic 的考量**：
- 你目前無嚴重光老化、無大面積色斑、無深細紋
- 5,500 vs 1,400 的價差不對應到 4 倍效果
- 待 6 個月後若效果 plateau，再考慮升級

**不選 The Ordinary 衍生物的考量**：
- 你已有屏障緩衝（Cicaplast B5）→ 可承受 L-AA
- 衍生物缺乏直接 RCT 證據

## 八、衝突 / 注意事項

| 情況 | 處理 |
|------|------|
| 同時用 AHA/BHA | Vit C 該日跳過或分開時段 |
| 微針 / 醫美後 | 暫停 7-14 天 |
| 曬傷 / 嚴重發炎期 | 暫停直到屏障修復 |
| 痘痘嚴重發炎 active | 局部跳過該區，痊癒後恢復 |
| 與 benzoyl peroxide | 氧化 Vit C → 兩者分開或不同部位 |
| 開封後保存 | 暗瓶 + 冷藏（4°C）延長壽命 |
| 變黃 → 變橘 / 變棕 | 已氧化，效力 < 50% → 棄用 |

## 十、Attribution 誠實表

回到本文起點的問題：「彈性光澤 + 下顎痘退是哪個元素的功勞？」

| 元素 | 主要貢獻路徑 | 確定度 |
|------|------------|------|
| 藍莓 150 g | 內皮微循環、光澤、發炎 | ⭐⭐⭐ |
| 鋅（南瓜籽）| 下顎痘 androgen 軸 | ⭐⭐⭐ |
| 亞麻籽 lignans | 抗雄激素、抗發炎 | ⭐⭐ |
| D3 3000 IU | 皮脂腺發炎調節 | ⭐⭐ |
| Retinol 0.1% | 毛孔、turnover、長期質地 | ⭐⭐⭐（但 < 1 週時效短）|
| Cicaplast B5 | 屏障修復、痘後修護 | ⭐⭐ |
| UVA Pro | 防新增傷害（守城）| ⭐⭐⭐ |
| 睡眠 + 鈉控 | 水腫、cortisol | ⭐⭐ |

→ **D+5 看到的改變主要來自「內皮 + 微循環 + 水分軸」的快效應**（藍莓 anthocyanins、Cicaplast 屏障修復、retinol 早期 turnover）。**膠原結構改變要 4-8 週才 measurable**，所以這段觀察期重點是「**維持 + 拍照基準**」，不是急著加新東西。

加入 Vit C 精華的目的：
- 為 **6 個月後的膠原密度 + 光老化阻斷**鋪路
- 與 retinol（PM）+ UVA Pro（AM 防）形成「**抗光老化金三角**」
- 不是為了 D+5 看到的快速變化（那些已經發生）

## 結語

你 D+5 的觀察是真實的、有 RCT 機轉解釋的，且**反映了「飲食代謝改善」與「外用 protocol 啟動」雙重效應**。下顎痘退場特別有價值 — 它比 HbA1c 抽血更早給了「代謝體質正在改善」的 visual feedback。

**加入 La Roche-Posay Pure Vitamin C10** 是合理的下一步，但**不是 D+5 變化的原因**，而是**為 D+90、D+180 的膠原 + 光老化軸鋪路**。當前 stack 已是 evidence-based 高品質配置，下一步重點是「**拍照建立 baseline + 維持執行率**」，而非追加新成分。
