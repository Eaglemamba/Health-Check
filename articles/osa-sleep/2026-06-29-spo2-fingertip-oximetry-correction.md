## 一、發生了什麼

User 至醫院接受**指尖夾式連續血氧監測（fingertip continuous pulse oximetry）**，看報告結果：**整夜 SpO2 完全平穩，沒有掉氧事件。**

這台儀器是**透射式（transmittance）**血氧——光穿過指尖組織量測，是醫療級脈搏血氧的標準量法，準確度遠高於 Garmin Venu 4 的**腕式反射式（reflectance）**。換言之，這是參考級資料，可以信。

**結論：先前所有「夜間掉氧」的數字都是量測假象。**

| 先前（Garmin 腕式）宣稱 | 指尖透射式實測 |
|------------------------|---------------|
| nadir 80–83% | 平穩，無顯著掉氧 |
| T90 7.4–18.4%（曾標「重度」） | ≈ 0% |
| 「14+ 晚連續 <88%」 | 不成立 |
| 最長 desat 30 min | 不成立 |
| 楔形枕 C1 T90 ↓75%（自然實驗） | 比較基準本身是 artifact，無意義 |
| 89% silent desat（HR coupling） | 事件本身多為假，分析失去前提 |

## 二、本專案其實早就預警過（不是全錯，是流程對了）

`2026-05-26-wearable-spo2-credibility-assessment.md` 白紙黑字寫過：

> 腕式反射式血氧的系統性誤差：精度遠低於指夾透射式；Garmin 官方標「非醫療用途」；平均誤差約 ±2–3%，低飽和區更差（讀「83%」實際動脈血氧可能 87–90%）；60 秒聚合會放大 T90 的衍生誤差。
>
> **唯一能同時解掉 artifact 與絕對準確度兩個疑問的方法 = 做一次 HSAT 校準真實 T90。**

**這次的指尖連續血氧，就是那個校準。** 所以正確的解讀不是「被 Garmin 騙了」，而是：

- 穿戴裝置的職責是**「提醒去查」，不是「下診斷」**——它拉了警報、催生了一次正確的醫療級檢查，這部分它做對了。
- 真正的教訓是**「預警 ≠ 行為改變」**：我們明明在 5/26 就標了不可信，卻仍續推 2 個月的設備介入與因果敘事。**任何要驅動數月介入的衍生指標，動手前應先用參考級儀器校準。**

## 三、淺眠原因重定向：四條證據自洽

缺氧排除後，「為什麼淺眠」回到平凡鑑別。User 後續回報的線索，四條全部指向同一方向：

| # | 線索 | 指向 |
|---|------|------|
| 1 | 指尖血氧**平的** | 無夜間缺氧、非氣道掐氧型 |
| 2 | 鎂甘胺酸 **100mg 就主觀有效** | 起作用的是 GABA / 自律神經放鬆軸，非氣道；且劑量低即有感 |
| 3 | **「想東想西、半夜起來看美股」** | 認知性 + 行為性喚醒 |
| 4 | **白天精力回升、沒這麼犯睏** | 反證無嚴重睡眠病理（真中重度 OSA 補不回白天精力） |

### 看美股為什麼是教科書級的睡眠破壞

美股交易時段換算台灣時間約 **21:30–04:00（夏令）**，**整段壓在睡眠正中央**。半夜起來看盤三路齊下：

1. **手機螢幕光** → 抑制褪黑激素，把人從睡眠拉回清醒
2. **錢 + 波動** → 交感神經飆高、念頭轉不停（= 「想東想西」）
3. **「等下要醒來看盤」這個念頭** → 製造**預期性醒覺（anticipatory awakening）**，大腦自動在那個時間把人叫醒 → 睡眠被切碎

這是 **psychophysiological / sleep-maintenance 型（醒覺維持困難）**：它**不掉血氧**（所以指尖血氧是平的），但照樣讓整夜變淺。一切對得起來。

## 四、重要的限制：別讓鐘擺盪過頭

指尖連續血氧**只測血氧 + 脈搏**，它**看不到**：

- 氣流 / 呼吸努力（airflow / effort）
- 腦波覺醒（EEG arousal）
- 腿動（EMG / PLM）

所以嚴格說：

- ✅ **「夜間缺氧」已排除** — 確定。
- ⚠️ **「完全沒有 UARS（arousal 型呼吸）或 PLMD」未排除** — 這兩者本來就不掉血氧，一台只有血氧的機器照不到。瘦型、年輕族群最常見的呼吸性睡眠問題反而正是不掉血氧的 UARS。

**因此**：缺氧驅動的整套心血管因果鏈（LVH / UA / HRV / 「225 小時/年缺氧」）已失去基礎、撤回；但「呼吸/肢動完全沒在干擾睡眠」要等行為調整後仍明顯淺眠、再做含 EEG+EMG 的**全套 PSG** 才能定論。目前先走最便宜、最可控的行為路徑。

## 五、新睡眠處方（行為性，取代設備/CPAP 路徑）

| 動作 | 機轉 |
|------|------|
| **看盤與床脫鉤**：床上不看盤、不放手機；用**到價提醒 / 限價單**取代「醒來盯盤」 | 移除預期性醒覺的觸發源 |
| **清醒窗禁螢幕**（尤其會引起情緒起伏的盤） | 保護褪黑激素、降睡前交感 |
| **鎂甘胺酸 100mg + Glycine 3g 續用** | GABA / 自律神經放鬆；睡眠目的維持 100mg 即可（劑量–效應已平，上修 300mg 的理由是血壓非睡眠，且過量致軟便） |
| **stimulus control**：真醒了睡不回 → 離床做無聊事，勿在床上滑盤 | 切斷「床 = 清醒/盯盤」的條件連結 |
| **待驗證 A/B 實驗**：耳塞/白噪音 on/off + 鎂 100mg on/off，各 5–7 晚記主觀睡眠 | 釘死「噪音」與「鎂」兩個假設 |

**槓桿轉移**：問題從「不可控的解剖構造（需 CPAP/設備）」變成「**高度可控的行為（夜間盯盤喚醒）**」。這是這三個月最好的消息——行為遠比氣道塌陷好修。

**延伸（自律神經/HRV 提升）**：缺氧排除後，HRV 偏低（~18）回到「自律神經 + 行為 + 有氧基礎」框架。呼吸以外的拉高槓桿（有氧 Zone 2 校正、移除抑制因子如酒精/晚餐/脫水）整理於 → [提升 HRV 實證指南 2026-06-29](../cardio-metabolic/2026-06-29-hrv-improvement-protocol.md)。
