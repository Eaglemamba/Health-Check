# 分析筆記：被蓋頭 rebreathing 機制與 OSA 判讀修正 — 2026-05-26

*非每日 check-in。本篇為「攝影機發現被蓋頭 rebreathing」的專題分析與 OSA 判讀修正，不含當日體重 / 血壓 / 睡眠實測值。*

---

## 重大發現：夜間 SpO2 desat 主因可能是「被蓋頭 rebreathing」，非解剖性 OSA

架設網路攝影機錄整夜睡眠後，直接觀察到以下事件鏈：

1. 睡眠中翻身，手伸進被子裡
2. 手抬起舉過頭時，把輕薄棉被一併帶起、覆蓋住口鼻
3. 約 1 分鐘後因吸不到空氣而驚醒，或反射性扯下被子才醒

### 科學機制：head-covering rebreathing → hypercapnic arousal

- **不是 OSA**（體內軟顎/舌根塌陷），而是**體外阻塞**（棉被蓋住口鼻）
- 棉被內密閉空間 → 呼出的 CO₂ 累積 + O₂ 耗盡 → 重複吸入廢氣
- 約 30-60 秒後 PaCO₂ 升至 ~50-55 mmHg → 化學受器（頸動脈體 + 延腦）觸發 cortical arousal → 驚醒
- 「1 分鐘才醒」= CO₂ 累積到覺醒閾值的時間常數，完全符合 rebreathing 生理學
- 機制與嬰兒猝死症（SIDS）的 head-covering 同源（SIDS 16-25% 涉及被蓋頭），但成人覺醒反射完整 → 能自救，不致命，但每次仍是一次完整的缺氧 + 高碳酸應激 + 睡眠片段化

### 手部動作定性：很可能是正常翻身，非 Restless 病症

- **不是 RLS（不寧腿）**：RLS 是清醒躺著時「不動就難受」的衝動，本案是睡著翻身才發生
- **不太像 PLMD**：PLMD 是週期性（每 20-40 秒）、刻板、小幅動作；本案是偶發、大幅、手舉過頭，較像換姿勢
- **最可能 = 正常睡眠翻身**（每晚 10-40 次）+「手舉過頭睡姿」剛好勾起輕被
- 真正要修的是**寢具幾何**（讓頭物理上蓋不到），不是神經系統

## 三條獨立證據匯流

### 1. 海拔悖論（決定性反常）

| | 家裡 | 日月潭飯店（5/16→5/17） |
|---|------|----------------------|
| 海拔 | ~10m | ~750m（含氧量低 8-9%） |
| 被子 | 輕薄、會被勾上頭 | 厚重、沒塞、不會鑽 → 不蓋頭 |
| T90 | 4.0-4.2% | **1.6%（7 晚最低 = 最好）** |
| nadir | 83-84% | **86%（7 晚最高 = 最好）** |

**邏輯**：若家裡 desat 是真 OSA，海拔 750m 應讓缺氧**更嚴重**（起點低、落在氧合解離曲線更陡處）。但日月潭反而是最好的一晚 → 唯一乾淨解釋：家裡有個飯店沒有的污染源 = 被蓋頭。

### 2. Stage-independent desat（5/19 紀錄的謎團）

- 5/15 深眠期 < 90% 達 28% — 深眠肌張力足夠，理論上不該塌陷，當時標為「強烈結構性訊號」
- 純 OSA 難解釋；**rebreathing 與睡眠分期無關**（任何階段手都會動 → 蓋頭 → desat），完美解釋
- → 5/19「深眠 28% → 鼻甲/鼻中膈/咽腔狹窄」的解讀應大幅下修

## 重要校正：Garmin 手腕血氧本身不準

整個「連 14 晚 < 88%、OSA 紅旗」警報建立在消費級手腕感測器上：

- 手腕反射式量測精度遠低於指夾透射式；Garmin 官方標示「非醫療用途」
- 平均誤差 2-3%，低血氧時更差（讀「83%」實際動脈血氧可能 87-90%）
- 睡眠中 motion + 手腕彎曲 + 冷氣房末梢冰冷 → 假性偏低
- T90 由手腕值衍生 → 誤差被放大

**最可能的真相是三者疊加**：
```
表面「低 SpO2」 = Garmin 量測假象 + 被蓋頭 rebreathing + 可能的輕度真 OSA
                  (感測器誤差)      (環境,可修)        (解剖,可能很輕,REM 相關)
```

## 修正後的風險判讀

- 當初「重度 OSA、PSG 最高優先、緊急 CPAP（反應率 > 80%）」的框架**很可能高估了真實嚴重度**
- 但**不從一個極端跳到另一個極端**：可能仍有輕度、REM 相關的真 OSA（5/19 REM 期 12.5% < 90%，肌張力最低，與被子無關的部分）
- **PSG 不取消**，但定位從「緊急」可能降為「確認性檢查」—— 用來定量「扣除蓋頭後的殘餘真 OSA」並徹底安心

## 下一步行動

### A. 物理消除 rebreathing（最高 ROI，今晚見效）
- [ ] 改用**成人睡袋**或**上下分兩條小被**（讓頭物理上蓋不到，繞過「手會不會動」變因）
- [ ] 或：被子上緣只到胸口 + 穿長袖暖睡衣
- [ ] 加重被（5-7kg）為備選（夏天偏熱）

### B. 攝影機 × Garmin 時間軸對齊（唯一能分離兩機制的居家方法）
